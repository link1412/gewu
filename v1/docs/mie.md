# 球形粒子的散射:`tools/mie.py`

S5 写的。汝釉要用:釉里有三种散射体,都按球算 [A]:

- 分相液滴:直径约 31–100 nm,和玻璃的折射率差约 0.01–0.05,体积分数不知道,可能 10–40%;
- 钙长石晶体:约 4.4 µm,n ≈ 1.58,玻璃 n ≈ 1.52;
- 气泡:约 80 µm,m = 1/1.52 < 1。

这个模块把「一群球在玻璃里」变成渲染器要的东西:σs、σa(1/mm)、g,要的话再给一张相函数表。算出来的介质交给 `tools/slab.py` 和渲染器。

## 结论

- 单个球的 Mie 和公开的参照值对上了:
  - Bohren & Huffman 书里的样例;
  - Wiscombe MIEV0 的 15 个测试例(含 m < 1、弱吸收、强吸收,x 到 10000),都在表里印的最后一位以内。唯一的例外是第 16 例,差 0.7–1 个末位,下面「验过什么」里有交代。
- 照抄 BHMIE 有两处不够准,都是参照值查出来的,改了:
  - **D_n 的起点。** BHMIE 从 n = max(nstop, |mx|) + 15 处令 D = 0 往下递推。吸收很弱时,这个零起点的误差只在 n > |mx| 的一段被压下去。m = 1.33 + 1e-5 i、x = 100,Q_sca 差 2e-5(MIEV0 第 10 例);x = 10000 时差 0.006(第 11 例)。改成在起点用 Lentz 连分式算出准确的 D,再往下递推。
  - **小 x。** BHMIE 的 a_n 分子是两个几乎相等的数相减,ψ_n 往上递推也在相减。x = 1e-4 时只剩 8 位,m = 1.02 时只剩 6 位。x < 2 时改写成对数导数之差(不再相减),ψ_n 用往下的比值连乘。
- 结构因子(Percus–Yevick 硬球)对分相液滴是大事 [D,下面的示例]:
  - d = 81 nm、φ = 0.2 时,σs 降到独立散射的 1/3.2(450 nm)到 1/3.9(650 nm);
  - 波长依赖从 λ^−3.6 变陡到 λ^−4.2,蓝更蓝;
  - g 从 +0.08 变成 −0.03。
  - 对钙长石和气泡(φ = 0.01),它只改正前方的衍射峰,σs 少 1–2%。
- 「有效介质」怎么取,在 φ = 0.2 时能让 σs 差 36%。我们默认按玻璃基体算对比度:弱对比时这是一阶 Born 近似给的结果,小角散射(SAXS)也这么算。理由和另两种写法见「近似」。

## 算什么

- `mie(m, x)`:给 Q_ext、Q_sca、Q_back、g。
  - m 是相对折射率,可以是实数或复数,可以小于 1;x = 2π a n_host / λ。
  - 约定按 Bohren & Huffman:时间因子 e^{−iωt},吸收写成 n + ik(k ≥ 0)。MIEV0 和 miepython 写成 n − ik,它们的振幅是我们的共轭。
  - Q_back = 4|S1(180°)|²/x²(BHMIE 的 QBACK)。
- `amplitudes(m, x, mu)`:给振幅函数 S1、S2(BH 式 4.74),μ = cos θ。
- `py_structure(qd, phi)`:给硬球的 Percus–Yevick 结构因子 S(q)。
- `medium(lam_nm, n_host, n_particle, d_nm, phi, structure=True, sizes=None, weights=None, phase_deg=None, effective=None)`:
  - 数密度 ρ = φ / ⟨V⟩,weights 是个数分数;
  - σs = ρ Σ w_i ∫ dσ_i/dΩ · S(q) dΩ,其中 dσ/dΩ = (|S1|² + |S2|²)/(2k²),q = 2k sin(θ/2);
  - σa = ρ Σ w_i (C_ext − C_sca),是粒子自己的吸收。玻璃不许吸收(复数 n_host 报错),釉自己的吸收在外面加;
  - g 是带 S(q) 的平均余弦;
  - 同时给不带 S(q) 的 σs、g,还有 S(0)、反照率,phase_deg 给了就给相函数(1/sr,全球积分为 1)。
  - n_host、n_particle 可以是随 λ 变的数组。
- `lognormal(d_median, sigma_g, n=50)`:对数正态的个数分布,给 sizes 和 weights [A:分布形状]。
- `maxwell_garnett(...)`:Maxwell-Garnett 等效折射率,`effective` 用。

## 方法和出处

**单个球**:

- 级数用 BHMIE(Bohren & Huffman 1983,附录 A),对 x 向量化。
  - 一批 x 先排序再分块,每块的工作数组不超过 4e6 个复数。
  - 每行到自己的 nstop 就冻住递推:小 x 的 χ_n 再往上会溢出。
- 项数 nstop:x > 8 用 Wiscombe(1980, Appl. Opt. 19, 1505,式 1);x ≤ 8 用 BHMIE 的 x + 4x^{1/3} + 2,比 Wiscombe 多一项,x = 1e-4 也有两项。
- D_n(mx) 往下递推,起点值用 Lentz(1976, Appl. Opt. 15, 668)的连分式,写法是 Thompson & Barnett(1986)改进的那种。MIEV0 也用 Lentz。
- x < 2 时:
  - a_n = (ψ_n/ξ_n)(D_n(mx)/m − D_n(x)) / (D_n(mx)/m − G_n),G_n = ξ_{n−1}/ξ_n − n/x;b_n 同理,把 D/m 换成 mD;
  - ψ_n = ψ_{n−1} / (D_n(x) + n/x)。x < π 时 ψ_n 没有零点,这样连乘是安全的。
- 振幅函数:π_n、τ_n 先递推出来,S1、S2 用矩阵乘法一次算出。

**一群球**:

- 就是干涉近似:单个球的微分截面乘结构因子,在全球上积分。
  - 这是 Magkiriadou et al. 2014(PRE 90, 062302)的式 3;
  - 也是 Vynck et al.(Rev. Mod. Phys. 95, 045003, 2023;arXiv 2106.13892)从平均光强推出来的散射自由程,式 111。
- 积分用 μ 上的 Gauss–Legendre,节点数 2·nstop + 4kd + 64。
  - S1、S2 是 μ 的不超过 nstop 次的多项式;S(q) 是 q² = 2k²(1−μ) 的整函数。所以积分在舍入误差内是精确的。
  - 节点数翻倍:液滴和钙长石变化小于 1e-10,气泡(x ≈ 1000)小于 1e-7(是 S1、S2 求和的舍入)。
- PY 结构因子:
  - 直接关联函数 c(r) = −(α + β s + γ s³),s = r/d < 1;α = (1+2φ)²/(1−φ)⁴,β = −6φ(1+φ/2)²/(1−φ)⁴,γ = φα/2。出处 Wertheim 1963(PRL 10, 321)、Thiele 1963;
  - S = 1/(1 − ρc(q)),ρc(q) 用闭式(Ashcroft & Lekner 1966;式子照 Kinning & Thomas 1984,Macromolecules 17, 1712,式 7–8 写);
  - qd < 1 时闭式要除以 Q⁶,会相消,改用定义积分的泰勒级数。
- 多分散:只用一个单分散的 S(q),直径取个数平均(或给定的 d_nm)[A]。解析的多分散 PY 有(Vrij 1979;Blum & Stell 1979),没做。

## 近似和适用范围

- **球。** 分相液滴按球算 [A]。钙长石是板条状,按球只是起点 [A]。气泡是球。
- **干涉近似。** 每个粒子照着只有基体的入射波散射,粒子之间的相位关联用 S(q) 记,别的多次散射都不算。
  - **可信的情况:单个粒子散射得弱。**
    - 液滴:|m−1| ≈ 0.013,x ≤ 1.5,ρ = 2x|m−1| ≤ 0.04。这时干涉近似就是介电涨落的一阶 Born 近似,相对误差是 O(Δε) 量级 [D]。
    - 再看 kℓs ≫ 1:ℓs 是毫米级,k 约 17/µm。所以 φ 到 0.4 也可用。
  - **不可信的情况:高 φ 又高对比。**
    - 比如 TiO2、二氧化硅光子玻璃(m ≈ 1.2–2)。近场耦合和反复散射都不能忽略,有效介质怎么取也会让结果差几十个百分点。
    - Magkiriadou 2014 在 m ≈ 1.2、φ = 0.55 时,看到模型在共振以外低估散射,他们归因于多次散射。
    - 我们的三种散射体里,只有钙长石在高 φ 时接近这种情况:ρ ≈ 4,每颗都是强的前向散射体;S(q) 只改 θ < λ/d 的那一点。到 φ ≳ 0.1,晶体彼此挨着,数就只能当量级看 [A]。
- **有效介质(`effective`)。** 三种写法:
  - **`None`(默认)**:波数和对比度都按玻璃基体。孤立的球,这就是精确的 Mie。弱对比时,一阶 Born 近似下散射强度正比于 (ε_p − ε_h)² ρ V² P(q) S(q)。q → 0 的「被挤开」已经在 S(0) 里,所以对比度应该对基体算。小角散射的 P(q)S(q) 也是这样。
  - **`"k"`**:波数用 Maxwell-Garnett 等效介质,对比度仍对基体。Vynck et al. 式 110–111 是「在基体里的 T 矩阵,在等效介质的波数上取值」;我们用 x = k_eff a 的 Mie 去近似它 [A]。液滴的结果比默认大 1.1%。
  - **`"km"`**:两样都对等效介质,m = n_p / n_eff。这是 Magkiriadou 2014 的做法:k 明确用 n_eff(其式 1–2);m 对谁,正文没有写,从 Fig. 7 图注「在等效介质里的对比 m = 1.2」推断是 n_p/n_eff [I,推断]。弱对比时它把对比度乘了 (1−φ),σs 就小 (1−φ)² 倍(φ = 0.2 时 0.64)。我们认为这是和 S(0) 重复计入了 [D]。它是给高对比光子玻璃的经验做法。
- **PY 本身。**
  - 是硬球流体的理论,φ 小于约 0.494(冻结点)时成立;再往上到 0.58–0.64,是亚稳的玻璃态,只能当近似;超过 0.64 报错。
  - S(0) 在 φ = 0.2 时比 Carnahan–Starling 低 1.5%(0.2090 和 0.2123),φ = 0.4 时低 7%(0.0400 和 0.0431)[D]。
- **分相液滴不是硬球流体**,这是最大的假设 [A]。
  - 液–液分相,无论是成核长大还是旋节分解,粒子周围都有贫化区,结构和硬球不同;旋节结构要用 Cahn 或 Teubner–Strey 的 S(q),或者用实测的 SAXS。
  - 尺寸多分散会压低 S(q) 的峰,单分散 PY 会高估结构的影响。
  - 所以「S(q) 让 σs 降到 1/3」只是硬球给的量级。真值要等汝瓷的 SAXS 或者电镜统计。
- **吸收不受 S(q) 影响** [A]。基体必须不吸收:吸收的基体里 Mie 要改写,没做。
- **相函数。** 钙长石 g ≈ 0.995,前向峰窄。HG 只能对上 g,对不上峰形,要准就用 `phase_deg` 的表。

## 用法

```
python3 -I tools/mie.py check
python3 -I tests/mie/test_mie.py
python3 -I tools/mie.py medium --lam 450,550,650 --n-host 1.52 --n-particle 1.54 --d 81 --phi 0.2 [--independent] [--effective k|km]
```

```python
import sys; sys.path.insert(0, "tools")
import numpy as np, mie
lam = np.arange(360.0, 831.0, 1.0)
sizes, w = mie.lognormal(60.0, 1.4, 50)                 # 中值 60 nm,几何标准差 1.4 [A]
r = mie.medium(lam, 1.52, 1.54, None, 0.2, sizes=sizes, weights=w, phase_deg=np.linspace(0, 180, 361))
r["sigma_s"], r["sigma_a"], r["g"]                      # 1/mm,1/mm,平均余弦,每个波长一个
r["phase"]                                              # (471, 361),1/sr
qext, qsca, qback, g = mie.mie(1.58 / 1.52, np.linspace(1, 100, 50))
```

## 还差

- BH 和 MIEV0 的参照值是二手转抄的,没对原书和 TN-140 原文。
- PY 没有和公开的数值表比,只验了极限、定义积分和硬核条件。
- 多分散 PY、非球的晶体、吸收的基体,都没做。
- 液滴的真实结构因子:要汝瓷釉的 SAXS 或电镜统计。没有之前,φ 和 S(q) 一起当未知量去拟合。
