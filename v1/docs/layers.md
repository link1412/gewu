# 分层:材质 → 工艺 → 物体 → 光学 → 运动

S3 定的(DESIGN §0)。材质、物体、光学、运动四层,分层以后可以参数化;在材质和物体之间加了一层「工艺」。

为什么加工艺:很多「材质的样子」其实是在某件器物上做出来的。开片取决于釉厚和曲率;积釉、紫口取决于器形;磨损落在高处;青花的浓淡来自笔。东方器物的美,一半在工艺。所以材质层只管物质本身和它的「脾气」,工艺层是在器物的几何上跑的过程。

## 每一层:管什么、用什么、怎么验

### 1 材质(`materials/<名>/`,文档 `docs/materials/<名>.md`)

- **管什么**:一种真实的物质,和用在哪件器物上无关。
  - 体光学:折射率 n(λ),金属另有 k(λ);吸收 σa(λ)、散射 σs(λ)、相函数 g;
  - 表面:粗糙度,由光泽度 GU 换算(`tools/gloss.py`);微起伏的统计,比如功率谱、坑和气泡的尺寸分布;
  - 薄膜、多层:珍珠层用特征矩阵(`shots/19-luodian/nacre.py`);
  - 色料:一族光谱 R(λ; c),c 是浓度,比如钴、铁、炭;
  - 「脾气」:驱动工艺的物性,比如釉和胎的膨胀差、剪滞长度、能磨多薄。
- **用什么**:
  - 数据的查找顺序:pbrt 自带的(金属的 n、k)→ 论文给的参数 → 实测库(USGS splib07、RGL-EPFL、refractiveindex.info)→ 我们拟合的(`glaze_fit.py` 按实测反射谱反解吸收和散射)。
  - 计算用 numpy/scipy,写光谱的数学、层模型、特征矩阵。
- **怎么验**:**材质卡**。
  - 一块标准试片,按一张真照片的比例尺(px/mm)和光去拍,和照片并排看;
  - 量化:按尺度的细节(`tools/detail.py`)和平光下的颜色;
  - 带三帧小角度转动,看高光、干涉色跟得对不对;
  - 能写成闭式解的,写单元测试(像 `tests/nacre/`)。

### 2 工艺(`crafts/<名>/`)

- **管什么**:在一件器物的几何上,用材质的「脾气」做出结构。输出是几何(网格、曲线)和贴图(高度、浓度、染色)。
- **用什么**,每种工艺一个模拟或生成器:
  - **开片**:断裂力学。应力张量场、裂尖生长、两代开片,用的是 06 的 `crackle.py`。输入釉厚场 e(s),输出裂缝网、深度、染色。
  - **流釉、积釉、紫口**:烧成时釉在器面上的薄层黏性流(润滑近似),在器面的网格上用有限体积算,输出釉厚 e(s)。
  - **雕**(剔红、玉、木):矢量纹样 → 距离场 → 按刀形(V 刀、圆刀)给高度 → 多层深度;剔犀、剔红的漆层按深度露出不同的颜色;刀痕。
  - **嵌**(点螺、螺钿、嵌金银):纹样排布 → 一片一片的多边形,每片自己的参数(片厚、层倾角)。19 的 `pattern.py` 是第一个。
  - **画**:
    - 青花的勾线、分水:笔触路径加笔肚的模型 → 钴在素坯上的浓度;烧成时向釉里扩散,边缘发晕。
    - 纸上的墨:guofeng 引擎的 MoXi 格子玻尔兹曼(`../guofeng`)。
  - **织、绣**:丝线是带捻的曲线(Cycles 有曲线图元),按针法排。
  - **过程**(旧是它们的结果):磨损按露出的程度(鎏金磨在高处),沁按扩散，铜器的氧化，积灰。
- **旧是过程的结果，不是一道工序**。
  - 只写物理过程和它的参数：氧化(铜的氧化亚铜、铜绿，银的硫化)、沉积(土、铁顺着裂缝沁进去)、磨损(高处摸亮、磨掉鎏金)、风化(釉面、漆面失光)、积灰。
  - 参数是物理量，带单位和出处;没有「年代」「做旧」这种外观旋钮。
  - 博物馆的参照多是旧器。材质卡对照片时，把这些过程的参数拟合到照片的状态([F]);材质本身的参数不能拿来顶替过程的效果。
  - 不是每件都旧：每件器物的过程参数按它该有的状态定，比如新青花全为零。
- **怎么验**:统计量对实物。比如开片胞径对 Lahlil 2013 量的 1.7–14.1 mm,线宽对 Met 照片;局部对博物馆的近照。

### 3 物体(`objects/<名>/`)

- **管什么**:器形;哪里用什么材质;调哪些工艺。
- **用什么**:
  - 器形:回转体用剖面曲线(样条),从有尺寸的博物馆照片量,06 的 `form.py`、`vessel.py` 就是这样做的;盒、盖、门钉、瓦这类写参数化的实体。
  - 网格:镜头看得到的地方加密(06 的 `PATCH_STEP`);UV 按回转体的 (θ, s) 天然给。
  - 规则:影响轮廓和视差的用真几何(位移);比一个像素还小的用凹凸贴图。
  - 输出:带 UV 的 PLY、EXR 贴图,以及一段 pbrt 子集的场景。
- **怎么验**:比例和轮廓对有尺寸的博物馆照片;在相近的光下并排看。

### 4 光学(`optics/`,相机链在 `tools/camera.py`)

- **管什么**:灯、背景、镜头、对焦、相机、构图。**美在这一层。**
- **用什么**:
  - 灯:写成数据的灯组,包括柔光箱、轮廓光、斜扫的硬光、渐变背景,每个光源带光谱(黑体或 LED 的光谱)。
    - 每组灯单独渲一张,线性叠加来调强度(skill-notes 第 24 条),要从 `mix06` 的草稿做成工具。
  - 镜头:薄透镜。按要对焦的面解对焦距离和光圈,微距的放大率;衍射在相机链里。要的话,在 pbrt 里用真实镜头的处方。眩光还在待办。
  - 相机链:5D Mark IV 的通道曲线、散粒和读出噪声、白平衡、色卡矩阵、色调、编码(DESIGN §5)。
  - 构图:弧的求解器,用机位去对原片某一镜的弧顶和矢高;背景色和物体色的对比。
  - 渲染:正片用 GPU 跑 Cycles,加 OIDN 降噪;pbrt 按光谱算,作参考。开发阶段只出预览画质:看效果 480×270,检查 960×540。
- **怎么验**:人工 review。那部参照片是标尺;要剪进片子时,再用 `compare.py check` 对弧。

### 5 运动(最后加)

- **刚体**:转台、机位路径,快门给运动模糊。要对原片时,用 `tools/flow.py`、`motion_fit.py` 按光流拟合。
- **便宜的**:在高分辨率静帧上推拉,原片第 1–3 镜看起来就是这样。
- **物理的**,只有动本身就是现象的镜头才用:
  - 墨晕:guofeng 引擎;
  - 金箔飘落:薄片在空气里的翻落,用有参数可查的准定常气动模型;
  - 走马灯:蜡烛的热对流推动叶轮;
  - 水面:波动方程。

## 参数化

- **每层一份参数**:每个参数写成 {值, 单位, 范围, 出处, 标记}。范围来自实测,比如官窑开片胞径 1.7–14.1 mm(Lahlil 2013)。
- **标记**,所有材质、工艺都用这一套(S3 统一;官窑釉第一轮的 I 是「推断」,要改过来):
  - [M] 量的:来源里报告的测量值，或我们自己从照片、渲染量出来的;
  - [I] 查到的:来源里给了值，但不是它自己量的，比如手册、图录、综述;
  - [D] 推的:由别的值算出来，写出算法;
  - [F] 拟合的:调到渲染和参照对上，是材质卡的输出，写明对的是什么、怎么拟合的;
  - [A] 假设:我们的假设或占位。
- **一张配方** = 物体(器形、材质、工艺的参数)+ 光学(灯组、镜头、构图目标)+ 运动。同一张配方加同一个随机种子,出同一张图。两张配方的差,就是改了什么。
- **好处**:
  - review 时能按名字改,比如「开片密一点」「钴浓一点」「换成苏麻离青」,预览几分钟就回来;
  - 同一套代码出一族器物,比如新瓷和老瓷、出土和传世;
  - 能反过来拟合:按真照片拟合材质参数。现在先用预览画质扫参数,用细节和颜色的量当目标;以后可以试可微渲染(Mitsuba 3,从 3.9 起有 Metal 后端 [查到,没试])。
  - 能看出哪些参数在画面里看得见,看不见的就不再细磨。
  - skill 就成了「写配方」,不用每次从头写场景。
- **守住的规矩**:
  - 材质、工艺、物体的参数必须是物理量,带单位和出处,不放「好看」的旋钮。
  - 审美的选择只在光学层:灯的位置、曝光、色调,都标成「我们的选择」。
- **工具**:`tools/build.py 配方.json --preview` → 场景 → 渲染 → 显影 → 并排图。等第一张材质卡过了再写,接口按它定。
