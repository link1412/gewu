# 第 27 镜:金箔(S9,着色器镜头)

- 原片 325–332,8 帧，金色的颗粒堆，上方有细碎的飘落物。我们做的是手工金箔碎片堆成的堆，加上飘落的金箔(`scene.py --frame K`,Cycles GPU 960×540 256 spp,每帧 ~6 s)。
- r1(v1,已提交):碎片小、揉得皱，有均匀的世界光，底色从深橙渐变到浅金。数字过了，但看上去像卡其色的碎石、枯叶，不像金。
- r2 [A]:
  - 光：黑棚，去掉世界光(金属在均匀的环境光下像哑光漆);左前一块大柔光箱 `key`,两盏小而亮的点光放在 `rim` 组里打闪光;高背光 `rim` 约 35°,低背光(`fill` 组)约 9°,给平躺在弧顶的碎片。原理是：朝相机倾 θ 的面，镜面映的是背后仰角 2θ 处。
  - 金箔：3 万片，大(0.8–3 mm×10)而平，顺着坡面躺(倾角 N(0, 9°)),8% 立起来打点状闪光;每帧抖 1.5°;锤打方向大致顺着弧(±25°),各向异性 0.5,粗糙度 0.05。
  - 色：两种金箔合金按视线仰角渐变，近处深 (1, .71, .23),弧顶浅 (1, .84, .45),都在金的 F0 (1, .78, .34) 附近。
  - 飘落:420 片 2–8 px 的碎屑，放在对焦面前后，成了虚焦的亮点。
  - 景深:f/1.2,对焦在弧顶，近处的面成了散景。
- 拟光 [F]:先对各光组的底图分别降噪，再拟(噪声加上凹的编码，会让拟合偏暗，降噪后反而亮 8–26 码);codefit 拟块均值 + 三条带均值(权重 1000),前向模型在 0 处平滑截断;光的颜色都绑在 key 上。
- 数字(`shotcheck 27 --film`,r2,第 329 帧，我们减原片，码值):全幅 RGB (0.0, +0.1, −0.1);中带 (+0.6, −1.2, −0.9);底带 (−2.7, +0.3, +0.4);top60 ≈ 0。8 帧全 PASS;剪辑点 [325, 333] PASS;弧顶 (0.49, 0.47) 对 (0.492, 0.467),矢高比 0.95。
- 遗留(看图，`out/check/27-film/side.png`):
  1. 太虚：原片整面基本在焦内，是细密的小闪点;我们中段以下全是大散景。
  2. 散景之间的底子有点灰褐，不够暖。
  3. 还没有原片那种顺着弧的长条反光(锤打纹)。
- 流程(S10 起):`python3 -I tools/shotkit.py look|run 27`,参数在 `shots/27-jinbo/shot.json`。S9 的 `shot.py`、`codefit.py` 等已删(8cd9ee3 可恢复);S10 在 kit 上重跑 `--round kit --no-film`:PASS,各区最大差 2.9 码(中带),弧顶 (0.491, 0.469),矢高比 0.96,和 r2 一致。片里还是 S9 的帧。
