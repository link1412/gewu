# 一件器物的一生:缺陷和磨损按物理做






这一节就是那次的计划。

## 原则

- 做的是同一时期、同一批次的另一件(DESIGN §0)。
  - 批次给参数:釉方、烧成曲线、器型、使用的习惯。
  - 这一件给随机种子。
  - 馆藏那件只用来量这一批的统计(多少个、多宽、多深、覆盖多少),不对位置。
- 缺陷和磨损都是过程的结果,按时间顺序做。每一步的输出是下一步的输入:
  1. **烧成**:釉熔化、流动、流平,气泡上浮、破口、愈合;
  2. **冷却**:开片(已做:`objects/ru_washer/cracks.py`,`crafts/crackle/`);
  3. **使用,几百年**:磨损、崩口;
  4. **沉积**:脏东西进裂缝、棕眼、划痕(包浆)。
- 每做完一样,就从 `objects/ru_washer/marks.py`(乘在图上的替身 [A])里删掉对应的一项。最后图里不剩任何乘上去的东西。

## 各项

| 缺陷 | 物理 | 怎么模拟、怎么渲 | 照片量什么 |
|---|---|---|---|
| 口沿淡边、积釉偏绿 | 熔釉的表面张力把釉从凸边拉走,往凹处聚;重力往下拉 | 釉流 `crafts/glazeflow/flow.py`(检查还没过,见 TODO)。出来的 e(s) 交给 `washer.py` 的釉厚,颜色自己出来 | 淡边的宽度 |
| 釉色不匀、釉面微波纹 | 浸釉的厚薄不匀;烧成时短波被流平,衰减 exp(−γ e³ k⁴ τ / 3μ),长波留下 | 在保角坐标上用谱方法,线性流平有解析解;剂量 τ 和釉流共用。得到釉厚场和釉面凹凸(凹凸贴图) | 明暗起伏的尺度 |
| 棕眼 | 气泡上浮(Stokes),到表面破口;釉黏,坑来不及愈合(黏性–毛细时间 μr/γ) | 按 `materials/ru_glaze/material.json` 的气泡撒点,算上浮和愈合;剩下的坑做成釉面真的凹陷(坑底釉薄、透胎),坑里进沉积 | 每 cm² 几个、大小 |
| 铁斑 | 富铁颗粒熔解,铁扩散出晕 | 釉里放小的吸收颗粒,边缘靠散射变虚 | 密度、大小 |
| 圈足火石红 | 足底刮釉或缩釉露胎,冷却时表面再氧化 | 釉流做足底的釉边;露胎处换成火石红的胎面材质 | 斑的覆盖率 |
| 磨损:圈足底 | 每次放下、挪动都蹭桌面;磨损体积 ∝ 载荷 × 滑动距离 / 硬度(Archard) | 足底不平(`washer.deviation`):低的几段先着地,磨得最重。磨深超过釉厚处露胎(改釉壳的几何);其余部分变糙 | 发白边的宽度、断续 |
| 磨损:口沿顶 | 倒扣、叠放、手拿;口沿起伏的高点先碰 | 同上;偶尔磕出贝壳状的小崩口(改几何) | 淡线宽度、崩口个数 |
| 磨损:外壁、内底 | 手摸只让釉面失光;笔洗内底有毛笔和清洗的细划痕,中心多 | 划痕几到几十 µm,比像素(约 90 µm)细,看得见的是变糙:做成釉面的粗糙度贴图(渲染底座支持,`docs/textures.md`),带方向 | 高光的宽度和亮度 |
| 包浆、沁 | 脏东西进裂缝、坑、划痕 | 官窑的沉积工艺 `crafts/deposition/`,接到裂缝、棕眼、磨痕上;主裂纹的褐线就是它 | 主裂纹的颜色、深浅 |

## 参数从哪来

- 黏度:按成分用 Giordano 2008 的熔体黏度模型算 [I]。
- 表面张力:按成分用加和系数算 [I]。
- 烧成曲线:查文献,查不到标 [A]。
- 气泡:材质里已有。
- 磨损系数、划痕统计、火石红的反射谱:待查(宋瓷足底、口沿磨损的显微照片;玻璃的 Archard 系数)。

## 顺序(按一眼看得到的程度)

1. 开片沉积(主裂纹发褐;最便宜,工艺现成);
2. 磨损:足底、口沿、失光(照片里的两条白边);
3. 釉流加流平(先修求解器的检查);
4. 棕眼;
5. 铁斑、火石红。
