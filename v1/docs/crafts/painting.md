# 工艺:画(青花的勾线、分水,烧成的晕散)

- 输出:钴的面密度图 c(x, y),g CoO/m²,`materials/qinghua` 的钴膜(`familymap`)读它。别的釉下、釉上的「画」(墨、彩)以后也走这一条,换颜料的族就行。
- 代码 `crafts/painting/paint.py`,参数 `crafts/painting/craft.json`,测试 `tests/qinghua/test_paint.py`。
- 坐标:mm;数组 [j, i],第 0 行在 y0(下边),和 `crafts/carving` 一样。`save_map()` 写 PFM(图像的第一行是上边),给 pbrt 的 imagemap、familymap 用。

## 规律(全是假设 [A])

- 调研(S3,qinghua-s3 第 5 节)没有找到:笔画宽度的实测、笔画横截面的钴分布、边和中心的比、积料的规律、分水的浓度规律。只找到:勾线在先、分水在线里填;分水是一支饱含料水的笔推着一汪水走;作坊说的「五、七、九色」是叫法,不是光谱上的档 [I,故宫词条;UMMA]。所以下面的规律都是我们的假设,参数放在 `craft.json`,等材质卡上对照片量、拟 [M、F]。
- **勾线**(`Canvas.stroke`):细笔沿折线走。
  - 落笔从 40% 宽在 `land_mm` 内压到全宽,提笔在 `lift_mm` 内收成尖;
  - 笔里的料越走越少,c 从头到尾线性降 `load_drop`;
  - 边在 `edge_mm` 内从满到无(笔毛的散开、料水渗进干坯);
  - `wobble`:手的抖,宽度慢慢变;
  - 一笔是一遍:同一笔里重叠的地方取最大,不叠加。
- **分水**(`Canvas.wash`):在一个闭合轮廓里填,c 连续(不量化成几档)。
  - 沿推的方向从 `c_start` 线性变到 `c_end`;
  - 边上多一圈料(水在边上最后干):乘 1 + `rim`·exp(−d/`rim_mm`),d 是到边的距离。调研说「边上积料可能只是画法,不是普遍的物理规律」[?];Met 18.61.2 的袍子上确实看得到边深(目测,没量);
  - 慢的斑驳:相对幅度 `mottle`,尺度 `mottle_mm`;
  - 边软在 `wash_edge_mm` 内。
- **叠加**:不同的笔、不同的分水,料相加。
- **烧**(`Canvas.fire`):高斯模糊,σ = `bleed_um`(材质的参数,`materials/qinghua/material.json`;现代 40 µm)。料的总量不变。

## 测试(`tests/qinghua/test_paint.py`,全过)

- 直的一笔 0.4 mm 宽:半高宽 0.400 mm;
- 料的衰减:x = 14 和 x = 4 处之比 0.839(公式给 0.839);提笔的尖 < 头的 20%;
- 分水:x = 5、15 处的 c 对线性渐变的值差 < 0.02;边内 0.06 mm 处有多出的一圈;12924 个不同的值(连续);
- 烧:总量比 1.00000000;阶跃的 10–90% 宽 150 µm,σ 60 µm 时公式给 2.563σ = 154 µm(像素 5 µm)。
- 样图:`out/qinghua/paint/leaf_preview.png`(一片叶子:分水、勾线、叶脉、一根茎,1-D 模型上色,没过渲染)。

## 材质卡上的第二张:我们自己画的(`materials/qinghua/card.py build --map craft`)

- 和第一张同样的光、比例、釉,花纹由 `card.craft_canvas()` 画:几块山石和一片衣褶(分水,有深有浅,有渐变)、轮廓的勾线、衣褶里的细线、一丛叶子(分水 + 勾线 + 叶脉)、一排栏杆的细线;40 px/mm 画,σ 40 µm 烧。
- c 用 `craft.json` 的 `line_c`(3)、`wash_c`(0.2–2)。
- 渲染在 `out/materials/qinghua/card_craft/`。
- 这是工艺的第一版。图形本身是程序摆的块,还不像画师的构图;要对的是线宽、边的软、分水的层次和边上的积料这些量,不是构图。

## 第一眼用的不是这个工艺(S3 第二轮)

- 第一眼(器物上的青花)用的是 Met 18.61.2 照片反推的 c 图,标明是借来的花纹(`docs/materials/qinghua.md`「第一眼」)。
- 原因:我们的花纹现在还是测试图(块、叶、栅栏),放到器物上会显得粗;第一眼要先把材质的好处显出来。
- 我们自己画的纹样,等够好了再单出一张,不和第一眼混在一起。
- 代码上这一轮只改了速度:`Canvas.stroke` 按笔的位置分块,只算笔周围的像素,长笔画(器物一圈 440 mm)也快;结果不变,测试全过。
