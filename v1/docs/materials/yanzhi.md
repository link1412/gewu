# 材质：胭脂红(金红珐琅)

S7 开工(imagery 第 23 条：原片的品红，约 sRGB (172,76,98))。第一轮只做材质层和材质卡。数据在 `materials/yanzhi/material.json`,每个数都带出处和标签([M] 量的、[I] 引的、[D] 推的、[F] 拟合的、[A] 假设的，见 `docs/layers.md`)。资料调研了两轮。

| 文件 | 做什么 |
|---|---|
| `enamel.py` | 金的 n、k(两张表),Drude 拟合，尺寸修正，Mie(`tools/mie.py`),κ(λ);Appen 折射率 |
| `stack.py` | 一维层：空气 / 珐琅(吸收)/ 釉 / 朗伯胎，各次反射全算，精确到平行层 |
| `digitize.py`、`validate.py` | 读 Takebe 2021 图 6 的实测吸收谱，拿模型去拟合 |
| `card.py`、`recipes/` | 材质卡：碗、灯、相机，量区域、算色差、出并排图 |
| `locus.py` | 不靠灯的检验：照片的红在不在模型的颜色轨迹上 |

## 结构(查到的)

- 白瓷胎 → 高温透明釉 → 低温铅玻璃珐琅，金以胶体颗粒分散在珐琅里。故宫两件残器的断面和成分(H18,侯佳钰等 2018《故宫学刊》19):
  - 康熙碗的胭脂红约 25 µm,直接施在涩胎上 [M];
  - 雍正盘的透明釉 180–200 µm [M],红层厚度没量到;
  - 出口瓷片的 ruby-pink 30–60 µm [M, Z25];典型的釉上彩 30–100 µm [I, B24]。
- 雍正胭脂红的成分(XRF,无标样，半定量)[M, H18]:SiO₂ 51.75、PbO 38.13、K₂O 2.90、Na₂O 2.28、Fe₂O₃ 1.14、Au₂O₃ 0.11 wt%,还有少量的 Mg、Al、Ca、Cu;硼测不了，而清代粉彩里有硼 [B24]。
- 粒径：清代没有原始的 TEM。
  - 18 世纪中国粉彩的透明粉红，金粒 20–60 nm [I, Kingery & Vandiver 1986,转引自 Barber & Freestone 1990,原图没见到];
  - 梅森的卡修斯紫，半径 16 ± 11 nm [M, C22];
  - C25 的拉曼谱定不出粒径。
- 测过颜色(反射谱或 L\*a\*b\*)的清代胭脂红，两轮都没找到。所以真值只有馆藏照片。

## 金的光学(`enamel.py`)

- 体材料的 n、k,两张表都带出处，放在 `data/`:
  - Johnson & Christy 1972,49 行;
  - McPeak 2015,141 行。它 300–390 nm 的几行超出了仪器标称的范围(400–1750 nm),好在可见光用不到。
- 尺寸修正(Kreibig):γ(R) = γ₀ + A v_F / R。
  - A = 0.25,v_F = 1.40 nm/fs [I, Berciaud 2005 p.517,单颗粒 5–33 nm 拟合的];
  - γ₀ 和 ω_p 用各自表的红外行拟 Drude [F]:J&C 给 ħω_p 9.07 eV、ħγ₀ 0.072 eV,McPeak 给 9.29 和 0.033。
  - Hu 2008 的 A = 0.33 用的是 L_eff = 4R/3 的约定，换算回来就是 0.25。
- 自检：水中 20 nm 的消光峰,J&C 521.3 nm、McPeak 517.7 nm,文献约 520 nm。
- 散射：粒径 20 nm 时，单次散射反照率在峰值处小于 2%、650 nm 处 7%;30 nm 时分别是 6% 和 21%;40 nm 时是 15% 和 39%。
  - 取 20 nm,把珐琅当纯吸收体。把散射算作损失，误差是 0.6–0.7 ΔE₀₀(一维层)。
  - 渲染里珐琅是一层薄膜，没有散射介质，所以不需要量路径上限(`slab.run`)。

## 对实测的金红玻璃(`digitize.py`、`validate.py`)

- Takebe、Okamoto、Mori 2021(J. Ceram. Soc. Jpn. 129:590)的图 6:1 mm 钠钙玻璃，含 Au₂O₃ 0.014 mass%,在 580/600/620/680 °C 显色，每片 9 个位置 [M]。
- 读图(`out/materials/yanzhi/takebe2021_fig6_digitised.png`,红线是中位数):
  - 读的是 PDF 里的 CMYK 栅格。PIL 读 Adobe CMYK 时是反的(255 = 没墨),要按「255 − 值」算墨量;
  - x 轴刻度的残差不超过 0.35 nm;
  - 读出的峰 517/526/533/544 nm,图上标的是 521±7/526±5/533±2/544±2 nm。
- 拟合：把吸收写成 a + b·κ(λ; d),在钠钙玻璃里(n_D 1.52 [A])扫一个粒径，看残差占峰值的比例:

| 图 | 实测峰 | McPeak, A 0.25 | J&C, A 0.25 |
|---|---|---|---|
| a | 517 nm | 7.4%(d 7.5) | 12.2% |
| b | 526 nm | 3.3%(d 7.5) | 8.5% |
| c | 533 nm | 1.1%(d 30;A 0.5 时 0.8%) | 4.7% |
| d | 544 nm | 3.6%(d 60) | 3.4%(d 40) |

- 定 McPeak,A 0.25 [D]。
- 没解决：在 n 1.52 里，任何粒径的 Mie 峰都不短于 528(McPeak)或 534 nm(J&C);a、b 两片的 517、526 nm 比这还短。图 a 的九条曲线本身就分得很开(505–525 nm)。

## 珐琅玻璃的折射率

- Appen 加和(`enamel.appen_nD`):用 H18 的成分算出 **n_D 1.590,阿贝数 39.8** [D]。
  - SiO₂、PbO、K₂O、Na₂O 的系数来自 1963 年手册表 72(调研第二轮转录了原页);Al、Ca、Mg、Ti 的系数用汝釉那套(EP3013762B1);
  - 铁、锰、铜、金没有系数，共 1.4 wt%,去掉不算。
- 对照：一种 PbO 38.2 wt% 的复原珐琅，椭偏量得 1.604 ± 0.006 [M, Palomar 2025;它的 K₂O 是 17.9%,波长没写]。
- 渲染器里顶面用的是釉的折射率 1.52 [A,同青花]。

## 一维层和渲染的近似(`stack.py`)

- 精确的一维层：空气 | 珐琅 n_e(吸收)| 釉 n_g | 朗伯胎。
  - 每个界面按 Fresnel,两个偏振取平均 [A],包括全反射;各次反射非相干地全加起来。
  - 自检：n_e = n_g 时和青花的 `optics.stack` 一致，误差 2e-16;τ = 0 时能量守恒到 1.00000。
- 渲染用的写法同 `tools/coat.py`:顶面一个电介质(n_g),胎上 4 µm 处一层 eta 1 的薄膜(透射 exp(−cκ))。这等于把珐琅放到了釉的下面。
  - 对纯吸收体，层的顺序不改变光，只有顶面的折射率有影响。c = 0.2–0.7 时，和精确的一维层差 **0.2–0.5 ΔE₀₀**;
  - 法向的镜面反射是 4.3%,精确值 5.2%(少 19%)。如果顶面改用 n_e,颜色反而差 1.2–1.8 ΔE₀₀。
- pbrt 的 RNEE 只穿一个折射界面，所以用一个界面也正合适。

## 量级核对

- 金：H18 的 Au₂O₃ 0.11 wt% 合 Au 0.098 wt%。按密度 3.6 g/cm³ [A] 算，柱密度 c 应该是:
  - 25–60 µm 厚时 0.09–0.21 g/m²;
  - 100 µm 厚时 0.35 g/m²。
  - 上博网页说金含量是「万分之一至二」[I],那就只有 0.01–0.05 g/m²。
- 卡上拟合出来的 c 是 0.34–0.67,是上面的 2–7 倍。**没解决**,可能的原因:
  - 单色碗的珐琅比彩绘的厚;
  - XRF 低估了金;
  - Met 的 JPEG 色调曲线压暗了深色。照片按 sRGB 解码 [A],真实的曲线不知道。
- 铁：起初怀疑铁在高铅玻璃里吸蓝光，把红推向橙。用调研找到的 R5 玻璃(PbO 25、Fe₂O₃ 1.00、MnO 0.24 wt%,Klysubun 2015 图 8,读图)按 1.14 wt% 换算。这个值连反射、锰、基玻璃都算进去了，是上限:
  - 40 µm 厚时，τ 在 450/550/650 nm 是 0.062/0.048/0.042,几乎是平的;
  - 颜色变暗 1.4–1.7 ΔE₀₀,色相只动 +0.3°。
  - **结论：铁解释不了色相**,最多让 c 小一点。v1 不加铁。

## 材质卡(`card.py`)

### 设置

- 真照片：Met 1971.180.248,雍正款，碗高 9.7 cm,口径 19.1 cm [I],CC0。只用侧面那张(2000×1333);底部那张能看到红面上清晰的窗形反光，说明面是亮的。
- 碗：卡用的夹具，不是物体层 [A]。
  - 外轮廓：按照片的剪影逐行量半宽(5.86 px/mm),行高按 5.69 px/mm 换算(相机仰 14°),再过平滑样条;口沿外撇、圈足和底是画的;
  - 壁厚 2.5 mm,口沿是半径 1 mm 的半圆;
  - 口沿是圆的(实物是花口)。
- 层：
  - 釉面是电介质：n 1.52,GGX α 0.003 [A,同青花];
  - 胎在釉面下 0.19 mm,是 ρ 0.85 的漫反射 [A];
  - 外面贴一层薄膜，从口沿顶下 1.2 mm(白边,[M] 量自照片)一直到圈足底的外沿。
- 光：`optics/rigs/museum_flat.json`(故宫的做法：两个 60 cm 柔光箱，在左前、右前 ±45°,加一盏顶灯，灰纸 18%),5500 K。
- 相机：仰 14°,碗高占画面 57%,100 mm 镜头。960×540,Cycles 256 spp(GPU 约 10 s);pbrt 光谱 64 spp(CPU 槽 40 s)。
- 量法：
  - 两张图都按各自的白(内壁远侧)逐通道归一;
  - 区域按各自红色的轮廓放：高度取红区的 30% 和 55%,横向取半宽的 −0.6、0、+0.6,共六个区;
  - 色差用 CIEDE2000;
  - 渲染用 raw 经过相机的白平衡和矩阵，不加色调曲线。

### 结果

| c (g/m²) | 渲染器 | 中间两区 ΔE₀₀ | 六区平均 | 中间的色相(照片 26.4–26.5°) |
|---|---|---|---|---|
| 0.20 | Cycles | 11.5 / 13.1 | 10.1 | 6.8° |
| 0.51 | Cycles | 2.8 / 3.5 | 4.9 | 22.0 / 22.4° |
| **0.56** | Cycles | **2.2 / 3.0** | 5.2 | 22.7 / 23.1° |
| **0.56** | **pbrt** | **3.5 / 4.0** | 4.8 | 22.7 / 23.4° |

- pbrt 和 Cycles 在同一 c 下差 1.2–1.9 ΔE₀₀。pbrt 更亮、更饱和，这是 Cycles 把光谱薄膜按通道平均造成的。
- **色相差主要来自深度**。开卡前我在 c 0.1–0.2 处比，说模型比照片偏紫 20°;那是比错了深度。金的吸收在绿光处饱和后，蓝光也被吃掉，红就转向橙:
  - CIE 色相：c 0.2 时 13°,c 0.4 时 27°,c 0.56 时 33°。
- 两侧的差(4–8 ΔE₀₀)是光的问题，不是材质的:
  - 照片两侧的亮度是正面的 2.3 倍，色度也更高;
  - 灯在 ±45° 时，渲染两侧只有正面的 1.05 倍;
  - 把灯挪到 ±75°(`recipes/yanzhi-card-red-az75.json`),两侧变成 1.7 倍，但正面的拟合 c 跌到 0.34。所以 c 被光的布局卡住了，只能给一个范围:**0.34–0.67 [F]**,v1 取 0.56。
- 不靠灯的检验(`locus.py`):对每个照片区域，同时拟合 c 和一个照度系数 E,看最小残差:
  - material.json 的设定：残差 **3.5–4.4 ΔE₀₀**,c 0.37–0.51;
  - J&C:5.1–6.3;McPeak 加 d 40:4.7–5.8;
  - 剩下的差主要是彩度：模型的 a\* 比照片高 8–11,色相低 3–4°。
- 相机本身就有份：同一个反射谱，模拟的 5D Mark IV 加 3×3 矩阵，和 CIE 观察者比，色相低 3–7°,ΔE₀₀ 2.1–4.7(c 0.4–0.56)。Met 用的什么相机、什么配置文件，都不知道。所以剩下的 3–4° 在相机的不确定度之内，**照片定不了它**。
- 原片的品红 (172,76,98):在模型的轨迹上，最合适的是 c 0.12,残差 2.8 ΔE₀₀(色相 3° 对 9°)。也就是说，原片那种品红是这套物理下的薄金层(胭脂水一类),不是 Met 碗的深红。

## 第二轮(S8):拟灯、收窄 c、查彩度

代码在 `materials/yanzhi/lightfit/`(每个文件的开头写了用法和假设);数据和图在 `out/materials/yanzhi/lightfit/`、`out/s8/yanzhi/r1/`(不进 git)。

### 先量照片(不靠渲染)[M]

- 内壁两块反光(JPEG 截到 255 的区域,亮度 ≥ 白的 1.12 倍):左 u −0.38、v 0.52,右 u +0.45、v 0.54(u 是半宽的比例,v 从远口沿到近口沿红边)。两块不对称,右边那块更靠外、更大。另有两块小的在远口沿下(u −0.40 v 0.08、u +0.52 v 0.15)。
- 外壁亮度(除以内壁的白),30% 高度那一行,u −0.8 → +0.8:R 通道 0.33 / 0.21 / 0.14 / 0.09 / 0.09 / 0.12 / 0.16 / 0.20 / 0.25;G 通道 0.042 … 0.010 … 0.020。
- 红上 G 通道几乎全是釉面的中性反光(金把绿吃光了;渲染里 c 从 0.5 到 0.8,R 降到 0.75 倍,G 只降 3%)。所以 **G 量的是「釉面映着什么」,R 量的是「透过珐琅的光」**,两者能分开拟。
- 背景纸:墙 0.66–0.73、脚前地面 0.41(紧贴)→ 0.74,都按内壁的白。**第一轮的渲染只有 0.09–0.19**:灰纸 18%、灯只照碗,环境暗了 4–8 倍。

### 拟灯

- 探针:一张 Cycles 渲染里放一格柔光箱对(方位 30–135°、仰角 20–60°、60 cm、1 m),每对一个光组,混合是精确的(`probe.py`、`fit.py`)。
  - **反光的位置定得住** [F]:仰 45° 时 az 60 的反光在 u ±0.37、v 0.60,az 75 的在 ±0.46、0.58;仰 60° 时 v 0.30。照片的 v 0.52 → 仰约 48°;左右不对称 → 左 60°、右 72°。
  - **亮度的拟合被探针本身带偏了**:几十块灯板同时在场,在别组的图里它们是黑的,但挡住了釉面映到的背景纸。照它拟出的灯单独渲出来,正面的反光 G 是 0.055,探针预测的是 0.01。之后只用「只放选定的灯」的干净渲染(`clean.py`;skill-notes 97)。
- 干净的拟合(`clean.py`):选定的灯 = 主箱一对(左 −60°、右 +72°,仰 48°,60 cm,1000 lux)+ 后侧一对(±135°,仰 45°)+ 顶灯;灰纸、白纸 × c 0.45、0.56 四张渲染,每张三个光组。光组强度精确;背景纸反射率在灰、白之间线性插值 [A,一次反弹为主];c 在 0.45、0.56 之间按对数插值 [A]。
  - 最好的:后侧 × 3(即 750 lux,主灯的 0.75),不要顶灯,纸的反射率 0.51,c 0.56–0.60 [F]。
  - 残差(对数的 RMS):R 0.28(约 ±30%),**G 0.92(约 2.5 倍)**,背景 0.15,脚前地面 0.19。
  - 灯的配置写在 `materials/yanzhi/recipes/rig_met_fit.json`(每盏灯带出处);它用 white_90(仓库里没有 0.5 的纸,`optics/backdrops.json` 不归这条线改),0.51 是灰、白两张插出来的。
- **G 对不上,说明照片的正面反光太弱**:照片正面 G 只有白的 1.0%;釉面在这个角度的反射约 4.5%,映到的是脚前约 9 cm 的地面(按外壁斜度 21°、相机仰 14° 推的 [D]),照片里那块地面是白的 0.69。4.5% × 0.69 ≈ 3%,照片只有 1%。可能的原因:
  1. Met 的 JPEG 色调曲线把暗部压低了(按 sRGB 解码 [A],真实曲线不知道)。这一条同时能解释正面比任何灯都暗、c 比 XRF 推算的高 2–7 倍 [I,未验证];
  2. 正面对着的地方有黑旗(博物馆常用,照片里看不到)[I];
  3. 珐琅表面的反射比 n 1.52 的釉低 [I,不太可能:珐琅 n 约 1.59,反射更高]。

### c:没有收窄

- 拟灯以后按亮度推 c,所有配置都要 0.9–1.3(正面太暗);按颜色(六区 ΔE00,`colourgrid.py`)最好的是 c 0.45、纸 0.45、只开主灯,六区平均 6.26。
- 两种推法不一致,根子在上面的「正面太暗」。**c 仍记 0.34–0.67 [F],material.json 不动。** 收窄要先定照片的色调曲线(待办 1)。

### 彩度:是釉面的中性反光,不是粒径(`diag.py`)

不靠灯的检验(同 `locus.py`:每个区拟 c 和照度 E,看剩下的 ΔE00),各换一项:

| 模型 | 六区平均 ΔE00 | 说明 |
|---|---|---|
| 原来的(20 nm,相机) | 3.95 | a\* 高 7–11 |
| **加一项中性反光 k** | **1.83** | k 拟出 0.7–2.2% 的白 [F],a\* 只高 1–4 |
| CIE 观察者代替相机 | 4.64 | 单换更差 |
| CIE 观察者 + 中性反光 | 1.21 | |
| 粒径 20–60 nm 均匀 | 6.20 | 更差 |
| 粒径对数正态(中值 30,σ 0.4) | 6.10 | 更差 |
| Kreibig A 0.5 | 4.34 | 更差 |

- 结论 [F]:**模型偏饱和,是因为不靠灯的检验没算釉面的反光;粒径和 A 不是原因(换了都更差)。** 粒径维持 20 nm。
- 渲染里反光由环境定(光学层):第一轮环境太暗,反光少,颜色偏饱和;这一轮把背景提到照片的亮度,反光又太多,正面 a\* 反而比照片低 3–6。所以彩度的问题和 G 对不上是同一个问题。
- 照片自身的检验(`veil.py`):把红墙像素拟成「E × 一个颜色 + 常数 k」,k 只有白的 0.4%,残差几乎不降。即照片的反光不是一个处处相同的常数,随位置变(两侧多、正面少)。

### 正面那层反光:排除了什么、剩下什么

照片正面 G 只有内壁白的 1.0%;渲染 3.1%。这一轮的检验(都是现成渲染上量的，便宜):

1. **不是脚前地面暗**:照片和渲染里，相机看到的脚前地面一样亮(照片 0.41 / 0.53 / 0.58 / 0.63,渲染 0.33 / 0.55 / 0.58 / 0.64,离脚 3–15% 碗高)[M]。正面映到的正是这块地(脚前 6–14 cm,按轮廓和相机算的 [D])。
2. **不是更远处暗**:地面在碗前 30 cm 截断(外面全黑),正面亮度只变 7%(`B-craft-c050-cut`)[M]。
3. **不像偏振镜**:沿正面一列,G 的「照片 / 渲染」在入射角 30°–55° 之间都是 0.30–0.36 [M]。偏振镜会在布儒斯特角(56.7°)附近把反射压到接近 0,比值应随角度大变 [D]。
4. **不像单调的色调曲线**:同一列上，渲染 G 0.002 的地方(圈足上沿)照片是 0.006,渲染 0.031 的地方照片是 0.010,渲染 0.045 的地方照片是 0.042 [M]。一条单调曲线要在 0.002–0.03 之间几乎是平的、到 0.045 又陡，不像相机的 S 形曲线 [D,弱:灯的分布仍可能有出入]。另外 Met 摄影室 2009 年以后的流程是「从线性曲线开始」、ColorChecker SG 做配置文件 [I,Geffert 2011,调研第四轮]。
5. **剩下的解释**:正面映到的那块地，从上往下看比从相机(仰 14°、掠射)看暗，即纸有掠射光泽 [I]。诊断渲染 `G1-sheen020`:脚前地面换成 0.2 的漫射 + 一层光滑薄膜，正面 G 0.0103、B 0.0125,照片 0.0101、0.0129 [M],吻合;但光滑膜把灯和碗也映出来了，相机看到的地面只有 0.12–0.15(照片 0.53–0.63),而且正面 R 跌到 0.045(照片 0.12)。
6. **正面的红从哪来**:地面暗了，正面的透射红也跟着暗。试了胎透光(`diffusetransmission`,r 0.78、t 0.17,壁透过约 7% [A,不是瓷胎的模型]):单独加,正面 R 0.12 → 0.16;和暗地面一起(`H2-transl-sheen`)正面 R 0.087、G 0.018,六区平均 **5.44**,正面两区 4.1 / 4.6。方向对，但两项都是假设，不定稿。

2. **照片处理时减了一个黑点偏移 → 只解释一部分。** 模型「照片 = (渲染 − b)/(1 − b)」,在外壁 18 个点上拟(`blackpoint.py`):

   - 不采用，只记下:馆方流程从线性曲线起步 [I,Geffert 2011],偏移从哪来没有证据。
