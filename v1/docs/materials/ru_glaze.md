# 汝窑天青釉(材质层)

S5 开工。我挑了汝窑。数据在 `materials/ru_glaze/material.json`,每个数带出处和标签(`docs/layers.md`)。

## 思路

- 釉的样子从化学和显微结构算，不从照片调:
  - 吸收：铁。Fe²⁺、Fe³⁺ 的摩尔吸收(Volotinen 2008 的分峰参数)乘以量出来的铁含量和价态;
  - 折射率：按成分算(Appen);
  - 散射：几种散射体，各自按量出来的尺寸和折射率差用 Mie 算(`tools/mie.py`),只有体积分数不知道，拟合 [F]。
- 拟合用一维平板的蒙特卡罗(`tools/slab.py`,和两个渲染器都对过，`docs/slab.md`),对的是同一片标本量的 CIELAB。
- 片子用 Cycles(GPU),pbrt 按光谱作参照。

## 标本

用 Shi 2020 的两片清凉寺出土天青釉：同一片上有成分(XRF)、釉厚、液滴尺寸、表面的 Fe²⁺/Fe³⁺(XPS)和 L\*a\*b\*(Ci7800)。缺：各相的体积分数、玻璃的密度、实测的 n(λ)、胎色。

| | R1(哑光、细开片) | R2(明亮细腻、开片) |
|---|---|---|
| 釉厚 | 511 µm | 532 µm |
| 全铁(按 Fe₂O₃) | 1.54 wt% | 1.48 wt% |
| Fe²⁺ 占比(表面 XPS) | 57.4% | 66.4% |
| 液滴均径 | 31 nm | 35 nm |
| L\*a\*b\* | 56.56, −6.00, 2.44 | 61.95, −5.30, −0.03 |

- Lab 的光源、观察者、含不含镜面反射(SCI/SCE)都没写。用 D65、CIE 1931 2°(手上只有 pbrt 的 1931 表;仪器常用 10°)[A];SCI、SCE 两种都算。

## 化学能直接算出来的(`python3 -I materials/ru_glaze/glaze.py`)

- 折射率(Appen,EP3013762B1 的系数,P₂O₅ 用 Duminis 2018 的;铁和锰没有系数，去掉后归一，去掉的约 1.6 wt%):
  - 整釉：R1 1.507,R2 1.502 [D];
  - 两相(Zhou 2023 另一片出土片的能谱):富硅相 1.516,富钙相 1.537(成排的富钙液滴 1.547),差 +0.021 到 +0.031 [D]。纳米相比能谱的作用体积小，会混进邻相，所以这是下限 [A]。
  - 钙长石(Medenbach 1997 实测，三个主轴的平均):577 nm 处 1.582 [M]。
  - 色散：没查到，阿贝数取 60 [A]。
- 铁的浓度:c = 20 ρ p / M(Fe₂O₃),密度 ρ 取 2.45 g/cm³ [A],按 XPS 的比例分 Fe²⁺、Fe³⁺(表面比例当体相 [A])。R2:Fe²⁺ 0.301、Fe³⁺ 0.153 mol/L。
- 吸收 σa = ln 10 (ε₂c₂ + ε₃c₃)(十进制摩尔吸收换自然对数):

| λ / nm | 400 | 450 | 500 | 550 | 600 | 650 | 700 | 750 |
|---|---|---|---|---|---|---|---|---|
| ε(Fe²⁺),钠钙定标 | 1.79 | 0.25 | 0.05 | 0.14 | 0.87 | 3.08 | 7.25 | 12.84 |
| ε(Fe³⁺),表值直接相加 | 1.06 | 1.08 | 0.67 | 0.65 | 0.77 | 0.90 | 0.82 | 0.59 |

### Fe²⁺ 的定标：用 a\* 在两种文献值里挑

- Fe²⁺ 的摩尔吸收在两种玻璃里差一倍：钠钙 30(Volotinen 用的 Bamford 值),E-glass 15.99 ± 0.09(Klement 2009 实测),都是 1000 nm 处的。汝釉是低碱的钙铝硅酸盐，成分上更近 E-glass,我先按 E-glass 缩放。
- 先用灰的散射把 L\* 调到量的值，a\* 就由化学算出来，不调:

| | 测的 a\* | 钠钙定标 | E-glass 定标 |
|---|---|---|---|
| R2 | −5.30 | −5.7 到 −6.7 | −3.6 到 −4.2 |
| R1 | −6.00 | −5.2 到 −6.1 | −3.3 到 −3.9 |

(范围来自 σs′ 2–4 /mm、SCI 和 SCE;胎 0.3 [A],釉面 α 0.05 [A]。)

- 量的 a\* 选了钠钙的定标 [F]:这是用一个量的数在两个发表的值里挑一个，不是预测。
- 还对不上的:
  - 两片的先后反了:R2 的 Fe²⁺ 多，模型里 R2 更绿，可量的是 R1 更绿(差不到 1)。
  - b\*:R2 预测约 0,对上了;R1 预测 +0.2 到 +0.5,量的是 +2.44。R1 的 Fe³⁺ 多，可模型里 Fe³⁺ 在蓝端的吸收太弱。Volotinen 的分峰是高斯形的，真玻璃的电荷转移吸收带有向可见光拖的长尾(Urbach 尾)[A],钛铁之间的电荷转移也没算(TiO₂ 0.13–0.16 wt%)。

## 散射

三种散射体，各按量出来的尺寸和折射率差用 Mie 算(`tools/mie.py`,`docs/mie.md`),只有体积分数是拟合的。R2 的玻璃里(n 1.504 @ 540 nm),钙长石和气泡每 1% 体积分数，液滴 10%:

| | 尺寸 | Δn | σs / mm⁻¹(450, 540, 650 nm) | g | σs′ = σs(1−g) |
|---|---|---|---|---|---|
| 钙长石 | 宽 800 nm 的对数正态(按体积),σg 1.6 [A] | +0.08 [M,Medenbach] | 7.98, 5.47, 3.73 | 0.96, 0.95, 0.94 | 0.31, 0.27, 0.24 |
| 富钙液滴 | 35 nm [M] | +0.021 [D] | 0.008, 0.004, 0.002(带 PY 结构因子;不带时翻倍) | 0 | 同左 |
| 气泡 | 80 µm [M] | −0.50 | 0.38, 0.38, 0.38 | 0.77 | 0.087 |

- **白从钙长石来，不从分相来** [D]。35 nm 的液滴、Δn 0.02,就算占 10% 体积,σs 也只有 0.004 /mm,比钙长石小近千倍;Δn 翻倍、粒径按 Zhou 2023 推的 126–160 nm 算，也还差一个量级。「分相乳光」在这组实测尺寸下撑不起汝釉的乳浊。
- **钙长石按针的宽度当球** [A]:针长几到几百 µm,宽几百 nm 到几 µm(Li 2005 的显微照片)。散射看的是窄的方向，所以用宽度。宽度直接决定要多少晶体:4.4 µm(Shi 2020 量的粒径)时 σs′ 每 1% 只有 0.093,要 27% 的晶体才够白，不像;800 nm 时 9%;400 nm 时 7%。宽度没有量过，是这里最大的假设。
- 钙长石散射偏蓝:σs′ 在 450 nm 比 650 nm 大 23%。
- 气泡的体积分数是假设的 1% [A],占 σs′ 的 3%。

### 给渲染器的一个相函数

- 渲染器的介质只收一个 Henyey–Greenstein g。g 0.95 的光要散射几百次才出来，渲染器的路径有上限(pbrt 的 maxdepth、Cycles 的 bounces,我们一直用 64)。
- 相似变换:保留每种散射体的 σs(1−g),都换成同一个 g\*。g\* 越低，散射次数越少，被上限截掉的越少;但离真的前向波瓣越远。
- `gstar.py` 用平板蒙特卡罗量(R2,540 nm,胎 0.3,α 0.05;和精确的混合波瓣、无上限比;噪声 0.5–0.7%):

| g\* | 无上限,0.1–1.0 mm 的误差 | 64 截断后，1 mm | 0.5 mm |
|---|---|---|---|
| 0.8 | −2.2% 到 +0.9% | **−24%** | −7% 到 −8% |
| 0.6 | −1.5% 到 +2.6% | −6.5% | −1% |
| 0.4 | −1.7% 到 +3.8% | −3% | −1% |
| 0 | −1.3% 到 +7.6% | −1% | +0.3% 到 +1.6% |

- 定为 **g\* 0.6、路径上限 128** [D]:128 时 1 mm 留下 99.7%,0.5 mm 100%;计算量约是 g\* 0.8 配 256 的一半。之前的 g\* 0.8 是在 0.5 mm、无上限的条件下验的，没算到截断。
- 官釉(σs 2.5 /mm、g 0.7、胎 0.12)在 64 时:1.2 mm 少 0.1%,2 mm 的积釉少 1.3%。问题只在汝釉这样强散射的釉上:它的 σs\* 是官釉的五倍。

## 色相：只靠铁，两片都偏蓝

- 钙长石的体积分数对 L\* 拟合以后(`fit.py`,胎 0.3、α 0.05),a\* 由化学给，可 b\* 两片都低:R2 −2.1(量的 0.0),R1 −1.3(量的 +2.4)(SCI;SCE 差不多)。
- 两种单参数的补法(`hue.py`,都只对 R2 的 b\* 拟合，R2 的 a\* 和 R1 的 a\*、b\* 是预测):
  - **尾巴**:Fe³⁺ 的电荷转移吸收带往可见光拖的尾，Volotinen 的高斯分峰里没有:ε = A exp(−(λ − 400 nm)/40 nm),每 mol/L 的 Fe³⁺。拟合出 A = 3.1 L/(mol·cm)(400 nm 处),量级合理 [I]。
  - **暖胎**:ρ(λ) = 0.3 (1 + t tanh((λ − 560 nm)/40 nm)),t = 0.20。

| | 量的 | 只有铁 | 尾巴 | 暖胎 |
|---|---|---|---|---|
| R2 a\*(SCI) | −5.30 | −6.46 | −7.17 | **−4.72** |
| R1 a\*, b\*(SCI) | −6.00, +2.44 | −5.59, −1.26 | −6.38, +1.09 | −3.14, +1.71 |
| R2 a\*(SCE) | −5.30 | −7.45 | −8.21 | **−5.52** |
| R1 a\*, b\*(SCE) | −6.00, +2.44 | −6.55, −1.81 | −7.47, +0.83 | −3.81, +1.38 |

- 定暖胎 [F]:它同时对上 R2 的 a\*(差 0.6 和 0.2),尾巴把 R2 推得更绿(差 1.9 和 2.9);台北故宫记「薄釉透胎呈粉红」,尾巴做不出粉。胎的谱形(560 nm 处的台阶，像烧成的胎里氧化铁的吸收边)是假设 [A],胎色没有实测。
- 两种都解释不了 R1:R1 的 Fe²⁺ 比 R2 少(0.88 对 0.98 wt%,按 Fe₂O₃),模型里它总是不如 R2 绿，可量的 R1 更绿(−6.0 对 −5.3)、更暗。R1 是哑光的;价态是表面 XPS(几个纳米深)量的，表面可能比体相氧化得多 [I]。如果 R1 的体相更还原，它会又暗又绿，两头都对。要体相的价态才能定，现在 R1 只作对照，参数用 R2(R2 的 66% Fe²⁺ 和 Chen 2020 古片的 65% 一致)。

## 色带卡(`card.py`)

- 一条楔形的釉，一头 0.1 mm、一头 1.0 mm,放在胎上;相机正上方，一个 300 mm 的柔光箱在 45°,不在镜面方向上(画面里没有反光)。釉是一个封闭的楔(Cycles 只在封闭的网格里填介质)。
- 读数(`card.py view`):白平衡按灯(5500 K 黑体),相机链的色彩矩阵，曝光按露出来的胎定(胎读它自己在 D65 下的 Y);沿楔每 0.1 mm 取釉宽中间的一半，出 L\*a\*b\*。**pbrt 的 LookAt 往下看时，画面的右是世界的 −x**:第一版读数左右反了(skill-notes 第 58 条)。
- 独立的预测(`card.py ref`):平板蒙特卡罗在卡的几何里(视线进、朝柔光箱出，互易),除以裸胎看柔光箱的投影立体角(Lambert 的多边形公式，和计数差 0.2%),过同一条相机链。

第一张(R2 SCI 的拟合，灰胎 0.3,g\* 0.8、上限 64)和改了以后(g\* 0.6、上限 128),L\* / a\*:

| 釉厚 | pbrt,0.8/64 | Cycles,0.8/64 | pbrt,0.6/128 | Cycles,0.6/128 |
|---|---|---|---|---|
| 0.1 mm | 46.9 / −1.6 | 47.7 / −1.9 | 47.7 / −1.7 | 48.0 / −1.8 |
| 0.5 mm | 57.0 / −6.1 | 57.3 / −6.8 | 58.5 / −6.9 | 58.6 / −7.7 |
| 1.0 mm | 60.4 / −7.6 | 60.5 / −8.5 | 65.7 / −11.1 | 65.4 / −12.8 |

- 64 的上限在 1 mm 处截掉了 22%(参照量的),两个渲染器一起暗;互相比只差 1 ΔE,看不出来。改了以后厚端亮了 5 个 L\*,也更绿。
- 和参照比(`card.py ref`,g\* 0.6、128,同一条相机链,10 万光子，所有波长同一个种子;朝柔光箱的计数有 1.4–1.5% 的标准误差):

|---|---|---|---|
| 0.1 mm | 47.7 / −1.9 / +0.2 | 47.6 / −1.7 / −0.8 | 47.9 / −1.8 / −1.0 |
| 0.3 mm | 53.2 / −4.1 / −1.8 | 53.1 / −4.2 / −2.1 | 53.3 / −4.6 / −2.2 |
| 0.5 mm | 59.0 / −6.7 / −2.4 | 58.4 / −6.9 / −2.7 | 58.5 / −7.6 / −2.9 |
| 0.7 mm | 62.7 / −8.8 / −2.4 | 62.5 / −9.1 / −2.9 | 62.5 / −10.3 / −3.1 |
| 1.0 mm | 66.6 / −10.9 / −2.6 | 65.6 / −11.1 / −2.7 | 65.3 / −12.8 / −3.2 |

  (L\* / a\* / b\*。)pbrt 的 a\* 和参照差 0.25 以内。L\* 在 0.5、1.0 mm 处低 2.5%、3.4%(按 Y),是参照噪声的 1.7、2.5 倍，两个渲染器彼此一致;不是侧面漏光(参照加侧边界量过，上限不到 1%),也不是 RNEE 把透射当光滑(光滑面反而亮 1%)。要定，参照得多跑十倍。
- 改了以后也更快(少散射):pbrt 304 s → 217 s(960×240,256 spp,12 线程),Cycles 87 s → 60 s(1024 spp,GPU)。
- Cycles 在厚处比 pbrt 绿(1 mm 处 a\* 差 1.7):吸收按通道平均后再取指数，路径越长越偏(`rgbscene.py` 的 RGB 近似)。终版的颜色以 pbrt 为准，或者给 Cycles 按厚度修正。
- 薄处暗：清的釉盖在胎上，胎的漫射光在釉面上全反射回去，又被胎吸收(参照:0.1 mm 的釉 R 0.159,胎 0.3)。所以「薄釉透粉」要靠胎色，不靠亮。
