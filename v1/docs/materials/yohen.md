# 曜变天目(稻叶天目)

S6 定的一比一复刻(DESIGN §0 的例外)。美来自斑纹周围的虹彩：结构色，主流说法是表面的薄层干涉，加纳米晶的散射(待调研核实)。

## 薄膜干涉的参照(`tools/tmm.py`,S6)

- 传递矩阵(特征矩阵)法，任意层数，复折射率 N = n + ik,s、p 偏振，光谱 360–830 nm(pbrt 的格点)。膜里相干，基底里不相干(黑釉把进去的光吃掉)。
- 两种独立的写法：特征矩阵和 Rouard 递推。`tests/yohen/tmm_check.py` 检查(都到 1e-15):裸界面、零厚度、同折射率的层、无吸收时 R + T = 1、矩阵对 Rouard(带吸收)、四分之一波长和半波长的闭式解、单层吸收膜的 Airy 公式、白和灰。
- 走过的坑：特征矩阵里 i 的符号跟着 N 的约定走。Macleod 用 N = n − ik,矩阵是 +i;我们用 n + ik,要 −i。无吸收时看不出来(|r| 不变),一带吸收就错，是「矩阵对 Rouard」和 Airy 两项抓出来的。

## 色带(占位的膜，都是 [A],等调研的 n、k)

`out/yohen/strips.png`:膜厚 0–600 nm,0°、30°、60° 看,D65 下的镜面反射。

- a. 膜 2.5(无吸收)在 1.6 的釉上：颜色饱和，一级蓝在约 100 nm。高折射率的膜里折射角小(60° 入射时膜里 cos 0.94),颜色随角度变得少。
- b. 膜 3.0 + 0.3i(像赤铁矿那样带吸收):超过约 250 nm 颜色褪成灰。带吸收的膜要薄才有色。
- c. 膜 1.5 在 1.65 的釉上(低折射率的硅质层):对比弱，颜色暗淡(最亮处的反射率 0.13,a 是 0.44)。出不来曜变那种饱和的蓝。
- 所以 [I,待核]:要饱和的蓝，膜的折射率得明显高于釉，厚度约 100 nm 量级;铁的氧化物说得通，低折射率的硅质层说不通。

## Cycles 的薄膜对参照(S6,`tests/yohen/cycles_strip.py`、`strip_compare.py`)

- Blender 5.2.1 的 Principled BSDF 自带薄膜(Thin Film Thickness、Thin Film IOR;只有实折射率，没有 k)。平板：黑底、光滑，膜厚沿 x 线性 0–600 nm,均匀的白天空，正交相机，像素就是 R(d, 角度)。
- 对参照(D65 下的线性 Rec.709),去掉两端各一列(像素跨到平板外，看到白天空):

|---|---|---|---|---|---|
| 2.5 / 1.6 | 0° | 1.81 | 4.35 | 5.56(357 nm) | 0.8% |
| | 30° | 1.83 | 4.28 | 5.48(364 nm) | 0.8% |
| | 60° | 1.36 | 3.05 | 3.71(381 nm) | 0.6% |
| 1.5 / 1.65 | 0° | 0.56 | 1.36 | 1.61 | 0.5% |
| | 30° | 0.52 | 1.35 | 1.59 | 0.5% |
| | 60° | 0.36 | 0.76 | 0.94 | 0.3% |

- 结论:Cycles 的薄膜够做预览;高对比、饱和的膜上差到 ΔE 4–5,终版用 pbrt 按光谱渲。Cycles 不能给膜加吸收(k),带吸收的膜(b)只能在 pbrt 里做。
- pbrt-v4 没有相干薄膜(仓库里的 `thindielectric` 是不相干的):补丁加了，见下一节。

## pbrt 的相干薄膜(S6,补丁 `Material "thinfilm"`)

- `ThinFilmBxDF`(`bxdfs.h`):GGX 微表面反射(和 `ConductorBxDF` 一样),菲涅耳项换成单层膜的 Airy 反射率 `ThinFilmR`,在微表面的余弦上、每个采样波长各算一次(BxDF 里存了这次的四个波长)。进了基底的光丢掉;可选的漫射底 ρ/π (1 − R(cos_i))(1 − R(cos_o)),R 取光滑膜的，不算底和膜之间的来回反射 [A]。
- 参数:`filmeta`、`filmk`、`eta`、`k`(光谱),`thickness`(nm,浮点贴图),`roughness`/`uroughness`/`vroughness`、`remaproughness`,`reflectance`(漫射底，默认 0)。`filmeta`、`eta`、`thickness` 没有默认值，缺了报错;`filmk`、`k` 缺了是 0。
- 验证:
  - 光滑的色带(`tests/yohen/pbrt_strip.py` → `strip_compare.py`,256 spp,三种占位的膜，各 0°、30°、60°):ΔE 中位 0.12–0.29,p95 ≤ 0.87,最大 1.72;亮度差 ≤ 0.1%。带吸收的膜 b 一样好。1024 spp 时 ΔE 中位 0.29 → 0.14、p95 0.87 → 0.40,按 1/√N 降：剩下的是光谱采样的噪声，没有偏差。
  - `tests/yohen/pbrt_checks.py`(1024 spp,30°):膜厚 0 的粗糙面和 pbrt 自带的 `conductor`(k = 0)逐位相同(alpha 0.1、0.3);150 nm 的粗糙膜对按 GGX 可见法线积分的 tmm 参照差 ≤ 0.04%(z ≤ 1.2;alpha 0.05、0.2);漫射底(ρ 0.5)对闭式解差 ≤ 0.05%。
  - 别的路径不变：`tests/rnee` 的釉板(on1、off1)和圆柱(on1),旧的和新的 pbrt 逐位相同。
- 坑:pbrt 的正交相机从上往下看时画面 x 朝世界的 −x(skill-notes 第 58 条又一次):色带一开始反了，看起来像大错。先用常数膜厚(0、150 nm)拆开，材质本身对到第四位，再反推每列的膜厚才找到。场景里把 u 反过来了。


## 调研

- 结论(报告的原话大意):公开资料不足以把稻叶的虹彩唯一归到一种纳米结构。候选有五种：薄膜干涉、表面二维周期起伏的衍射、短程有序纳米结构的相干散射、晶体本征吸收、膜–微球复合(杭州团队)。它们的角分布不同，不能随便相加。
- 能用的数字(都不是稻叶原件，标明样本):
  - 藤田原件(无损，阿部 2023 的大会摘要):光彩区反射峰 420–500 nm;光彩区和黑地 XRF 组成没有差别 [M]。
  - 建窑古片(Chen 2022,只读了摘要):入射 5° 时无明显峰,20° 时 419 nm 峰;二维铁氧化物晶体约 30–40 nm 宽、15 nm 厚 [I]。
  - 长江/福嶋的窑片(福嶋 2022 p.44):表层约 40 nm、析出体 0.1–0.2 µm、周期域 600–800 nm(SEM/FFT)[M,古片]。
  - 海老塚 2023(国宝油滴的照片拟合，模型):周期 900 nm、峰谷 50–100 nm [F,不是实测]。
  - 黑釉：建窑片的成分(山崎 1994 表 1,只读了索引),玻璃相 n ≈ 1.538(波长未说)。
  - 光学常数：赤铁矿(o、e)、磁铁矿的 n、k(Querry 1985,380–780 nm);ε-Fe₂O₃ 没有可用的可见光 n、k。
  - 稻叶:高 7.2、口径 12.2、足径 3.8 cm,276 g(故宫 2018 p.23)。
- 没有的：稻叶的膜厚分布、物相、校准过的角谱;杭州专著(李伟东、方肖鸣 2023)的数据章节;藤田 2023 全文。
- 下载到论文 16 篇、图 20 张、视频 1 段;静嘉堂官网、DNP 预览、Dejoie、山崎 1994、水上 2013 没下下来。
- 参照图(稻叶):1955 年图版的正俯视(`inaba_commons_1955_full.jpg`,PD-Japan,黑白印刷后上色的色不可信，斑点的位置能数);三菱 2025 的斜俯视彩色照(`inaba_mitsubishi2025_img-1-2.jpg`,700 px);Internet Museum 2025 视频 53.5 s 的一帧(1080p,展柜光)。视频里稻叶只有约 2 s 近景，几乎不动，量不了随角度的变化。
- 我从图上看到的 [A,目测]:三菱照和视频帧里，蓝晕和斑核外的银白边在整个内壁上都亮，黑地却是暗的。如果蓝晕只是光滑面上的薄膜，颜色只会出现在高光方向，黑地在同样的方向也该反出灯来;所以晕区的反射是离开镜面方向的：粗糙的膜、衍射或散射。藤田的 Key-museo 照(点光、正俯视)则是满碗的蓝。

## 斑点的位置(S6,`objects/yohen_inaba/spots.py`)

- 来源:1955 年图版的正俯视(1388×1429)。颜色是印刷时加的，只用位置。输出 `out/yohen/spots/`:`spots.json`(每个斑核的像素中心、面积、等效半径、r/R_口、方位角，还有全部阈值)、`classes.png`、`overlay.png`。
- 分类：黑地 / 蓝晕 / 斑块(斑核之间的浅色区和外圈的亮边)/ 斑核 / 遮掉的(照片的高光、碗外)。
- 用了哪些特征(都在 CIELAB 里，平滑过):
  - 斑块：被亮带围住的区域。亮带指每个斑核的浅圈和斑块的外圈，它们比周围的 L* 高得最多。
  - 斑核有两条路，取并集:
    - (a) 斑块里棕色的地方，即 min(a*, b*) 高。斑核又红又黄;黑地只偏红(b* ≈ 0),浅圈只偏黄(a* ≈ 0)。
    - (b) L* 的盆地(灰度填洞以下 3 以上),在脖子处切开;要紧凑，大部分边是盆地自己的边而不是切线，四周 16 个扇区里至少 70% 有亮带。用来找亮带太淡、围不成斑块的暗斑核(井边那一圈)。
- 走过的弯路：
  - 只用暖色 a* + b*:印刷的暖色调连黑地也盖了，斑块占了 68%。
  - 只用「比周围暗」:斑核比黑地亮，只比自己的浅圈暗;这样取到的是兔毫的条纹。
  - scipy 的 `watershed_ift` 在全图上跑，没种子的斑会被邻居的标号淹掉，标号不连通;换成 skimage 的 `watershed(mask=...)`,没种子的连通块自成一个。
- 结果:378 个斑核;面积占比黑地 66.3%、蓝晕 4.3%、斑块 19.1%、斑核 10.2%(去掉遮罩后)。口沿圆：中心 (690.2, 725.7),R 625.3 px,边缘残差中位 4 px(3 px 内 41%;左下的投影拉的)。
- 目测检查 [A]:外圈的斑块几乎全对;井边密的一圈暗斑核大约漏四分之一，有几个只框了半边(中心是暗的、只有边是棕的)。阈值都是对这张图目测定的 [A]。
- 图版不是正交投影，碗壁越陡，斑越扁：位置要等器形和相机定了再投到碗面上。

## 器形(S6,`objects/yohen_inaba/{measure,form}.py`)

- 来源:1937 年图版的侧视(上半，高橋《大正名器鑑》6,PD-Japan),浅色底，从上面约 15° 看。`measure.py` 量边：轮廓(上、侧、下)和近侧口沿亮带的下沿。`form.py` 把车床剖面和这张照片的相机一起拟合，比例尺用馆藏口径 122 mm。做法照搬汝窑洗(`objects/ru_washer/form.py`)。通用的几何(回转面的投影轮廓、点到折线的距离)抽到 `tools/lathe.py`。
  - 对 ru_washer 的拟合结果逐位相同(`tests/lathe/check_vs_washer.py`)。
  - 两处修正，汝窑洗里的那份没有：一段轮廓两头都会合时，先从中间切开，否则拼接的那头随参数翻转，另一头的缺口一跳几十像素(圈足就这样，拟合卡死)；平的环带(圈足底)算「到了头」。
- 剖面：圈足(底、外面，上宽下窄)→ 一圈几乎平的露胎底面 → 釉的厚边(圆角)→ 外壁(三次样条，9 个节点)→ 鳖口的凹槽(圆角)→ 外翻的口沿带 → 半圆的唇。
- 结果(`objects/yohen_inaba/form.json`;残差的中位：轮廓 1.7–2.9 px,口沿亮带 6.8 px;约 16 px/mm):
  - 高 68.3 ± 0.6 mm,馆藏记 72 [M]:**差 5%,冲突，没有用馆藏的高**(和汝窑洗一样，以照片为准、标明)。足径(底)40.0 mm,馆藏 38;
  - 口沿带高 3.7 mm、外翻 2.2 mm,凹槽在 z = 64.6 mm;
  - 圈足高 6.5 mm,下宽 40.0、上宽 44.0 mm;
  - 这里不能解释的:1955 年俯视图的口沿拟成椭圆，长短轴比 0.988,不够解释 5%;换成高为准，口径就变成 127 mm,和足径也更对不上。
  - 侧面下部左右各有一块鼓出(釉的垂流)，车床剖面做不出来，靠鲁棒拟合放过(侧面残差 p90 12 px)。
  - 用 1955 年的另一张侧视(`inaba_commons_1955_01.jpg`,相机不同)再拟一次，能独立地查这 5%:还没做。
- 内侧照片上看不到，全是假设 [A](`form.json` 的 `assumed`):
  - 唇厚 3 mm;
  - 壁厚从凹槽处的 3 mm 线性增到外壁根部的 w_low,底厚同 w_low;
  - w_low 由馆藏重量 276 g [M] 和密度 2.3 g/cm³ [A] 反推，得 8.2 mm(密度 2.2–2.4 时 8.8–7.6);
  - 于是内底在 z = 14.7 mm、深 53.6 mm,平底半径 17 mm,10 mm 的圆角接内壁。
  - 1955 年俯视图上两道高光的月牙在半径约 20 mm,大致就是内底转内壁的地方，对得上，但这不算量过。
- 输出:`out/yohen/form/fit.png`(拟合的轮廓画在照片上)、`section.png`(剖面)、`fit_section.png`(两者并排)。
