# 透明层罩在漫射体上(釉罩胎、漆罩色)

- 用处:青花(透明釉罩白胎,钴在交界)、剔红和别的漆(透明或有色的漆层罩色层)、釉上的一层清漆。凡是「上面透明、下面漫射、中间可能夹一层吸收」的,都走这一条。
- 做法:**真几何**。三层面分开放:漫射的底、可选的吸收薄膜、透明层的上表面;透明层里可以有吸收介质。两个渲染器读同一个场景:pbrt(打过补丁,光谱参考)和 Cycles(`tools/rgbscene.py` → `tools/cycles_scene.py`)。
- 工具:`tools/coat.py`。测试:`tests/qinghua/gen_coat.py`、`run_coat.py`、`check_coat.py`。

## 接口(`tools/coat.py`)

```python
from coat import coat_medium, coated_tile, write_quad
write_quad(scene_dir)                                   # 单位正方形 coat_quad.ply(两个三角形,带 u、v),每个场景写一次
text = coat_medium("lacquer", sigma_a=[l0, v0, l1, v1, ...])  # 1/mm;透明层不吸收就不要这一行
text += coated_tile((x0, x1), (y0, y1), z_base=-h, thickness=h, eta=1.52, alpha=0.003,
                    medium="lacquer",                   # 或 None
                    base='Material "diffuse" "texture reflectance" "fam"',   # 或均匀的 "spectrum reflectance"
                    film='Material "thindielectric" "float eta" [ 1 ] "texture transmittance" "co"')  # 或 None
```

- **底**:任何 `diffuse`:均匀的反射率,或 `familymap`(一族光谱,浓度图选成员,`docs/textures.md`)。
- **薄膜**(可选,底上方 `film_gap` = 4 µm):`thindielectric`,`eta` 必须是 1,`"transmittance"` 是它在法向一次穿过的内透射率 T₀(λ),可以是光谱、浮点,或 `familymap` 纹理(随位置变,比如钴的浓度)。斜着穿过时透射 T₀^(1/cos θ),θ 是在透明层里的角度。用来放「只吸收、没有厚度」的一层:釉下的钴、清漆下的色。
- **透明层**:上表面 `dielectric`(`eta`、GGX `alpha`,`remaproughness` false,`refractivenee` true),厚 `thickness`;有 `medium` 时层里是均匀的吸收介质(不散射)。
- 坐标:mm,z 向上,法向朝上;UV 在整块上从 (0,0) 到 (1,1),底和薄膜一样。
- 没有侧壁:光在层里横走过了边,在两个渲染器里一样地出去。所以块要比画面大(横走最多几 mm),或者像 `materials/qinghua/card.py` 那样在画面外围一圈不带图案的块。
- 曲面的器物(以后,物体层):同样三层,用网格(三角形)做,彼此沿法向偏移。

## 为什么用真几何(量出来的差别)

- 透明层里的全反射把底的光送回底(白釉下约一半),这一圈回收:
  - 让白更亮:1-D 模型(`materials/qinghua/optics.py`,n 1.52,胎 0.85),有回收 0.660,没有 0.319;
  - 让蓝更深更饱和(相对白):c = 1.5 g/m² 时蓝、白之比,有回收 R、G、B 0.13、0.23、0.46,没有 0.24、0.40、0.65。
  - Cycles 的 Principled 涂层没有这一圈回收,pbrt 的 `coateddiffuse` 有,但它的介质是灰的(厚度是光学深度、反照率是散射的),放不了按光谱吸收的钴;两者都是局部的 BSDF。
- 回收的光在层里横着走,一跳 2h·tan θ,h = 0.3 mm 时 ≥ 0.5 mm。局部 BSDF 看不到这一点。渲染量出来的差别(青花的钴,c = 3,同一场景 0.3 mm 和 0.02 mm 两种厚度,pbrt):
  - 0.5 mm 宽的线变浅 25–30%(最暗处对白:0.3 mm 的 R、G、B 0.056、0.156、0.435;0.02 mm 的 0.044、0.120、0.345);0.2 mm 的线浅 13–15%;
  - 大块的蓝(2 mm 外)只差 3%;
  - 阶跃的边(10–90%)从 0.14 mm 宽到 0.26 mm(红、绿);
  - 离图案 2.5 mm 的白暗 2%(光走进钴里被吸掉)。
  - 所以是看得见的:细线和边缘的软。这就是选真几何的理由。

## 两个渲染器里怎么算

- pbrt(`patches/pbrt-v4-gewu.patch`):
  - `familymap` 纹理:原生实现,按光谱取族的成员(λ 线性插值,c 线性插值,c 在两头外取端点)。
  - `thindielectric` 的 `"transmittance"`:带吸收的薄板,两个面和中间所有次的反射都算(eta 1 时就是一次 T₀^(1/cos))。
  - 折射光连接(RNEE,`docs/rnee.md`)穿过薄膜时乘它的透射率。S3 修了一个老问题:连接的方向没归一化就拿去算余弦(`SpawnRayTo` 的方向不是单位长);薄膜吸收以后才看出来(钴带暗了 1.6–4 倍)。修后 `tests/rnee` 和 S1 的表一致(釉板 1.0005,圆柱 1.0016)。
  - **层用三角形,不用 bilinear patch**:pbrt-v4 的 bilinear patch 求交会拒绝 t < gamma(30)·(|o| + |d| + 各角的 |p|) 的交点,在 pbrt 以相机为原点的渲染空间里约是到相机距离的 9e-6 倍(400 mm 时 3.6 µm)。薄膜下 2 µm 的底就被跳过,整块变黑(量的:400 mm 处 2 µm 黑,50 µm 正常)。三角形的求交在以射线起点为原点的坐标里,不受这个限;剩下的限制是新射线起点的偏移,约 4e-7 × 距离(400 mm 时 0.17 µm),4 µm 的间隙到几米都够。
- Cycles(`rgbscene.py` 写 JSON,`cycles_scene.py` 搭节点):
  - 薄膜是 Transparent BSDF,颜色从一张 c × μ 的查找表来(μ = |cos|,33 档),每个通道的单次透射取 T_ch(c, μ) = √(通道平均 T₀^(2/μ))(「p = 2」投影,权重是传感器 × 主光)。下进上出两次穿过同角度时是精确的;算上全反射回收,1-D 研究里是精确值的 0.94–0.99。
  - 层里的吸收介质:Volume Absorption,系数是通道平均(`rgbscene` 原有的办法)。
  - `familymap` 底:每个成员的反射率按通道平均(原有)。

## 验证(`tests/qinghua/`,S3)

- 场景(`gen_coat.py`):相机正上方 400 mm,一盏 150 mm 的面光在 50° 高,300 mm 远;960×540,画面 64 × 36 mm。
  - 块 A:白底 0.8,钴膜(`materials/qinghua` 的 κ,c 图 25.6 px/mm),三条宽带 c = 0.5、1.5、3,线宽 0.2、0.5、1、2 mm(c = 3),一个阶跃;透明釉 n 1.52,光滑,0.3 mm,不吸收。
  - 块 B:编的一族红色底 R = 0.85 exp(−c k(λ))(k 在 580 nm 以下是台阶),c 沿 x 从 0 到 1;罩一层编的黄色吸收层(σa = 0.6 exp(−(λ−400)/60) /mm),0.3 mm。
  - 变体 thin:同一场景,三层都在 0.02 mm 里(几乎不横走)。参考:同一盏灯下反射率 0.5 的漫射板。
- 解析的对照:1-D 叠层(`optics.stack`,所有次的反射、全反射),对灯面 24×24 个方向积分,逐波长,再按传感器 × 5500 K 加权成三个通道;和参考板之比。
- pbrt 256 spp,Cycles 1024 spp。区域离边 ≥ 2 mm。结果(渲染 / 解析,R、G、B):

## 没做的

- 侧壁、曲面(物体层的事)。
- 层里的散射(乳浊的釉、含颜料的漆)。现在介质只吸收。
- 粗糙的上表面只在反射上粗糙,透射仍是光滑的(`refractivenee` 的规矩,`docs/rnee.md`);Cycles 里两者都粗糙。釉的 α 很小(0.003),差别看不出。
- 两个没解释清、留着的数:
  - pbrt 对 1-D 解析,c = 3 的红通道 +4%(厚薄一样,不是横走);
  - Cycles 里饱和的底罩吸收层,最暗的通道暗到 16%(RGB 的多次反弹,每跳乘通道平均)。青花终版要不要分波段渲,等材质卡看差多少再定。
