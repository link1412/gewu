# 配乐

原片的音乐不能用,要有原曲的感觉。时长灵活,只出音乐,不合成到视频里。

所以:**听感取自原曲,音符是我们自己写的。** 录音不进片,原曲的音没有抄。

**我听不见声音。** 下面的「像」都是量出来的,只说明频谱、电平和结构接近,不说明好听。第一版数字都对上了,听感还差一点;主音是人声也是听出来的,我原先判断成吹奏。好不好听要靠耳朵判断。

**现状:** 两版都可用。我选 B:轮廓和原曲一样,先低、跳高、再落回中间,旋律也更有起伏,目标又是有原曲的感觉。A 更贴「苟日新」的声调,「新」落在最高音上,但这条线没人唱出来。这是我按结构和测量做的选择,我听不见。A 留着,要改就重跑 `score.py A`。

**结构改过。** 片子放慢后从约 24 秒变成约 30 秒,旧结构放不下:第一条字幕到日出 16 秒,18 拍只有 68 BPM;片尾加速后,最后三个音落在片子结束之后。旧版留作 `out/v2/music/v1_mix_*.wav`,旧音色在 `bank_v1/`。改动:

- 时间改用 `film.shown`(放慢和加速之后真正放映的帧),原来读的是 `len`。
- 第一条字幕到日出从 18 拍改成 30 拍,回到约 113 BPM。音符和声部的顺序没变。
- 循环从第 3 拍起,第 2 拍是循环最后一个音,落在第二镜的切点上,作弱起。
- 回家的三个音提前:前两个留在日出段里,轻;主音正好落在名字出现的那一拍。这是片尾加速逼出来的改动,听感没验证。
- 人声统一降 2 dB,连混响一起,在 `score.py` 的 `LEAD_DB`。
- 铺底音色从持续 28 秒加长到 38 秒。弦乐前 20 秒和旧的逐样本相同;簧风琴重渲后前 20 秒的电平差不到 4%。

## 定稿:`mix_G_mit3.wav`

片子的人声和弦乐换成 MuseScore General 0.2(MIT,源自 Fluid R3),低音和簧风琴的 Keyscape 不变,音符和混音也不变:用旧音色重跑,和 `mix_G_fire.wav` 逐位相同,所以差别只来自音色。33.12 秒,−16.4 LUFS,−1.4 dBTP,最深限幅 −2.0 dB,没有爆音候选。`bake.sh` 默认用它。

**试了三版:**

- 第一版,直接换加校准:每个音取最稳的一段(直接换时 E5 低 30 音分)、切音响度对齐旧版、长音单独校音(最多差 26 音分)。前半段听着像一男一女,旧版是两个女声。量到主旋律三个音来自三份录音,1200–1800 Hz 是 −26.6、−8.9、−15.1 dB,旧版是 −8.0、−8.7、−8.9。这个落差听起来像两个人是假设,没有单独验证。
- 第二版,每个音从整个合唱里挑谐波最接近旧版的录音,移调到目标音。切音音高平均绝对偏差 7.8 音分,旧版 9.2。声音有点刺耳。量到 1–4 kHz 最多高 6.2 dB。
- 第三版,在第二版上给每个音加一个静态滤波,谐波对齐旧版的同一个音。对旧版:两段大波浪各频段差 ±0.4 dB 以内,留白 ±0.6 dB,日出 2–4 kHz +1.6 dB,名字段 1–2 kHz +1.9 dB。定稿用这版。

**旧音色只留下了数字。** `voice_mit.json` 每个音存四样:用哪份录音(`root`)、切掉开头多少秒(`cut`)、滤波(`filter_db`)、切音增益(`chop_gain`)。后两样是和旧版 TimbresOfHeaven 的同一个音量出来的,所以新人声的谐波电平是照着旧人声调的。重跑不需要那个音色库。

**跑:**

```
curl -O https://ftp.osuosl.org/pub/musescore/soundfont/MuseScore_General/MuseScore_General.sf2    # 215,614,036 字节,sha256 ee51d2c4b1525e70f19a45909c4fd7a2e26d91d115fa89dbf5a6bc413d8b9bf3
python3 -I v2/music/voice_mit.py MuseScore_General.sf2    # 出 out/v2/music/bank_mit/
python3 -I v2/music/score_g.py                            # 出 out/v2/music/mix_G_mit3.wav

```

`bank_mit/` 里的 Keyscape 音色(`low_*`、`high_*`)是指向 `out/v2/music/bank/` 的链接,要先有它们,见「怎么跑」。`score_g.py` 还要 `out/v2/music/ref.wav`,它是原片的音轨,`check.py` 从原片抽出来,只用来量频段电平(`follow()`),不进混音;原片不在仓库里。量过:这样重跑,和选定的混音 md5 相同(`86b857ee3f03c016255e8e58e0001443`)。

## G 版(`score_g.py`,F 加对位),**选定**

**片序(我定的):** 南红之后改成金箔、德化、荷花、螺钿竹、狂草、一滴、黑伞、孔雀羽、南珠、黄花梨、青花、金鱼、珐琅、火,再日出。前面只对调红灯笼和剪纸,第一次高潮停在白色的剪纸上,切到黑底的南红时明暗反差更大;第一个「又日新」还是南红,留白不变。理由:长镜头在第二次上涌的前半段,切点越到后面越快,最后一个循环停在火上,木炭的亮度也在上升。南珠不再贴青花,青花和珐琅也隔开了,颜色冷暖交替。金鱼不再接日出,这是改了之前的设计。原来的火放在孔雀羽和德化之间。

此前所有声部都唱同一个三音音型,是卡农。G 保留音型和半拍卡农,从第一条字幕起,用两条长音线代替下方重复音型的两个声部:对位线一个循环一个音,逐步上行(第一遍 D5 E5 F#5 E5,第二遍 F#5 A5 B5 A5 F#5 A5 D6);低音线反向(第二遍 D3 B2 A2 F#2 A2 B2 A2),停在 A2,切日出解决到 D。留白里两条线都不唱。

**量的:** 和 F 比,线上的音在混音里的增量:D5 +21 dB、B2 +11 到 +15 dB,这些听得出是新线;F#5、A5 只有 0 到 +6 dB,因为音型和铺底本来就有这些音,独立性可能不明显。长音是同一个合唱采样拉长,颤音是加的。旋律没听过。

**和原片的关系:** 量到的原片是音型、卡农加持续低音,没有逐音记谱,没量到独立长线(频谱判断)。所以 G 比原片更复调,F 更像原片。

## F 版(`score_f.py`)

E 的声音对了,感情不到位,意象也像比原版多。量的:原版 38 镜,日出前约 16.3 秒,平均 .43 秒一镜;我们 33 镜,日出前 28.56 秒,平均 .87 秒一镜。镜头不多,是长。E 把原版约 7.6 秒的累积拉到 18.4 秒,这是我认为张力被摊薄的原因(判断,听不见)。

**做法:** 声音和 E 相同,原片的弧走两遍。第一遍到第一个「又日新」(16.52 秒,原片在约 16.1 秒收),滤波器合上;南红 1.36 秒是留白(原片约 1.25 秒);扫开正好落在金箔的切点,第二遍更大,到日出。「新」的高音第一遍 F#5,第二遍 A5,最后一个循环 D6。第一遍比原片电平低 3 dB,让第二遍更大。

**落点随片子:** 留白的位置跟第一个「又日新」镜头和下一个切点走。加木炭和山楂后是 17.6、18.96、30.56 秒。留白这一拍的速度算出来 132 BPM,因为只有一个远处的人声,不明显。

## E 版(`score_e.py`,声音对了,感情不到位)

D 没感情。方向定为越像原片越好。

**底线:** 不用原片的录音和声音,不逐音照搬它的旋律(F#4 E5 A4)。音乐风格和结构不受限。旋律相似到什么程度算侵权我判断不了,参赛前该问懂的人。

**E 取自测量的:**
- D 大调,音型 A4 F#5 E5。音高类别和原片同一组,顺序和音区不同。

**还不一样的:** 人声还是合唱采样切的;片子字幕到日出的累积比原片长约 2.4 倍;日出和名字段是原有写法。

## C 版(`score_c.py`,不如原片舒服)

## 我们的

- **调和音**:降 E 宫调,五声。
- **A**:循环 G4 C5 F5(角 羽 商),两个四度叠上去。音程 +5 +5 −10,原曲 +10 −7 −3。
- **B**:循环 B♭4 F5 C5(徵 商 羽),先低、跳高、落回中间,是原曲的轮廓。音程 +7 −5 −2。中间那个音和原曲同一音级(九度),比 A 近。
- **依字行腔**:循环对「苟日新」三个字的声调。最高的音「新」随字幕一路上升:F5 → G5 → B♭5 → C6 → E♭6,然后切日出。
- **落点**:全片到最后一个音,主音才第一次落在主旋律上(E♭5)。
- **铺底**:E♭ 大调加九度、六度,E♭2 B♭2 E♭3 F3 G3 B♭3 C4 E♭4 F4 G4。
- **铜钟**:切日出和名字上各一下。原曲没有,是我加的,在 `stems_*/bell.wav`,去掉不伤别的。

## 落点

全从 `v2/cut.json` 读,剪辑改了重跑就对齐,不用动画面。拍号由 `Clock` 按原曲的速度算,跑的时候会打印。如果每拍偏离 .44–.62 秒,它会报错,不会硬凑。下面是 32 镜、29.8 秒时的值:

| 拍 | 秒 | 对齐 |
|---|---|---|
| 2、5、6 | 1.40、2.92、3.44 | 第 2、3、4 镜的切点 |
| 7 | 4.00 | 卡农第二声部进,原曲约 4 秒 |
| 18 | 10.16 | 第一条字幕,低频上冲,第三层进,滤波器打开一档 |
| 33 | 18.16 | 最后两个声部进,第一条字幕和日出的正中 |

每拍 .507、.52、.56、.533、.504 秒。验证结果:没有爆音候选,这些点上最近的起音偏差中位约 16 ms,日出那一拍 −69 ms。

## 量得出来的差距

- 建段里主音一颗颗的清晰度不如原曲:原曲的分音是干净的亮线,前后暗;我们的是一片碎点。合唱采样内部有好几个人在拍,这可能是原因,没有验证。
- 建段后段 1500–6000 Hz 低 4–8 dB,90–300 Hz 的频段差在 −7 到 +2 之间跳。
- 中频的起伏还是比原曲小:500–1000 Hz 摆动 11.3 dB,原曲 17.0 dB。120–250 Hz 11.6 dB,原曲 17.5 dB。

## 怎么跑

定稿的跑法在最上面。这里是 Keyscape 铺底和 A–F 这些放弃的版本,它们的人声和弦乐用 TimbresOfHeaven。音色只要渲一次,放在 `out/v2/music/bank/`。SF2 用 fluidsynth 渲:

```
F=TimbresOfHeaven.sf2
python3 -I v2/music/sf2.py $F 52 voice 43,46,48,53,55,58,60,63,65,67,70,72,75,77,79,82,84,87 2.2 100
python3 -I v2/music/sf2.py $F 49 str 39,46,51,53,55,58,60,63,65,67 38 90
python3 -I v2/music/bank.py "Harmochord - Dronescape Deep" low 39,46,51,55,58 38
python3 -I v2/music/bank.py "Harmochord - Ambient Reeds" high 58,63,65,67 38
```

然后:

```
python3 -I v2/music/score.py A    # 约 15 秒,出 out/v2/music/mix_A.wav 和 stems_A/;B 同理
python3 -I v2/music/check.py out/v2/music/mix_A.wav     # 和原曲比频段、声场,出 check_mix_A.png
python3 -I v2/music/verify.py A   # 爆音、音高、落点
```

- Keyscape 的离线渲染工具(`khost`、`keyscape.py`)碰的是付费音色库的内部格式,没有公开。`bank.py` 要调用它们,所以 Keyscape 那部分音色在这个仓库里重现不了。
- `patches.py` 量候选音色的起音、延音、声场。

## 替代品

- 主音是合唱采样切短的,不是独唱;气息是加的,因为采样里没有。换一段真人独唱的「啊」可能是最大的升级。
- 钟的分音比和衰减是估计,不是量的编钟。基音调低调短了:原先它是安静段里最响的线,120–300 Hz 比原曲高 13 dB。
- 铺底是 SF2 弦乐加 Keyscape 的 Harmochord(簧风琴)。弦乐采样有最多 16 音分的偏差,`measured_cents` 逐音量过再校准,校完主要分音在 4 音分内。63、65、67 三个弦乐采样基频和二次谐波差 32 音分,一个比例校不准,不用,那几个音由音准的簧风琴担。
- 主音每个音也按「实际读到的那一段」(0.10–0.40 秒)校准,这段最多差 13 音分。
