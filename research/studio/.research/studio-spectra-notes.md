# Studio LED and xenon spectra — research notes

## Deliverable and data conventions

Created `aputure_amaran_al_m9_dimmed_{9,7,5,3,1,0}of9.csv` and `godox_ad200_{h200j_adft200,h200,h200r,h200j_ftsts40w}_1over128.csv`. All are **measured data**, not estimated SPDs. Each CSV has a source comment, `wavelength_nm,value`, and independently peak-normalized relative **radiometric energy** values. The CSVs were extracted from the original R serialized numeric double vectors; no graph digitization, wavelength interpolation, spectral fitting, or blackbody substitution. Independent normalization discards absolute brightness and relative brightness between dimming settings.

Pinned source repository revision for all data: [62fd04a618de16baccf2ab255ef019c87a1596cb](https://github.com/aphalo/photobiologyLamps/tree/62fd04a618de16baccf2ab255ef019c87a1596cb). Data processing by the original author is retained; the exported values are measured/processed data, not raw instrument counts.

## High-CRI photographic LED: Aputure Amaran AL-M9

**Manufacturer's specification:** CCT **5500 ± 200 K**, **CRI >95**, **TLCI >95**. [Aputure product manual, printed p. 5, “Specifications” table (PDF page 6; preserved by a rental company)](https://www.delight.rent/upload/iblock/3c2/1004320.pdf#page=6). This is a compact photographic/video **fill light**, not a large studio COB fixture; its spectrum should not be relabeled as an Aputure 300d, 600d, or other model.

**Measured data:** Pedro J. Aphalo's `amaran_m9.mspct`, six dimming settings, **9/9, 7/9, 5/9, 3/9, 1/9, 0/9**, at **160 mm**, with diffuser installed. Ocean Optics Maya2000 Pro spectroradiometer, Bentham cosine-corrected input optics. [Original data file, six named collection members](https://github.com/aphalo/photobiologyLamps/blob/62fd04a618de16baccf2ab255ef019c87a1596cb/data/amaran-m9-mspct.rda); [author's package documentation, “Details” and “Note”](https://github.com/aphalo/photobiologyLamps/blob/62fd04a618de16baccf2ab255ef019c87a1596cb/man/amaran_m9.mspct.Rd); [author's measurement article, “Light output” and “Dimming,” Figs. 6–8](https://www.photo-spectrum.info/pages/illumination/led-fill-lights-2.html).

**Original processing / export limits:** the author's build script smooths the measurement, thins wavelengths, and fills data below **390 nm** with zero. The exports therefore omit those source-filled zeros and preserve the actual remaining source wavelengths, **390–898.97 nm**, with uneven sampling. Tiny negative tail values in dimmed curves are measurement/processing residuals and are preserved, not silently clipped. Labels such as **0/9** are the author's setting labels: this curve has nonzero output and must not be interpreted as “off.” [Author's build script, `smooth_spct`, `thin_wl`, `trim_wl`, and final member names](https://github.com/aphalo/photobiologyLamps/blob/62fd04a618de16baccf2ab255ef019c87a1596cb/data-raw/Maya-video-LED/make-amaran-lamp-mspct.R).

## Xenon photographic flash: Godox AD200

**Measured data:** four energy-SPD curves at **1/128** flash power: H200j bare-bulb head with stock **AD-FT200** tube; H200 Fresnel head; H200R round head; and H200j with replacement **FT-ST-S40w** tube from Xenon Flash Tubes (Israel). These are flash emission curves, not the LED modelling lamp. Ocean Optics Maya2000 Pro array spectrometer + Bentham **D7-H** diffuser; original dataset metadata says distance **unknown**, and the author's article describes approximately similar distances between heads. [Original data file, `maya_flash_lamps.mspct`, four named collection members](https://github.com/aphalo/photobiologyLamps/blob/62fd04a618de16baccf2ab255ef019c87a1596cb/data-raw/maya-flash-lamps.mspct.rda); [original build script, naming, measurement metadata and processing](https://github.com/aphalo/photobiologyLamps/blob/62fd04a618de16baccf2ab255ef019c87a1596cb/data-raw/Maya-flash/make-maya-flash-lamps-mspct.R); [author's account, “Spectra from different heads,” Fig. 2](https://www.photo-spectrum.info/pages/illumination/Godox-AD200.html#spectra-from-different-heads).

The source curves are already normalized and wavelength-thinned by the author, then exported with independent peak normalization over their retained **315–800 nm** range. They describe those particular heads/tubes at that power setting, not a universal xenon lamp or other power levels. The author's article plots photon fluence; the exported R dataset's `s.e.irrad` column is the **energy** spectrum, so it is not a digitization of the photon-fluence figure. [Dataset build script and `s.e.irrad` source vectors](https://github.com/aphalo/photobiologyLamps/blob/62fd04a618de16baccf2ab255ef019c87a1596cb/data-raw/Maya-flash/make-maya-flash-lamps-mspct.R).

**Manufacturer's specification (context only):** Godox AD200 color temperature **5600 ± 200 K**; [Godox instruction manual, printed p. 42 “Technical Data,” color-temperature row (PDF page 11; manufacturer-authored manual mirrored by a retailer)](https://www.didnegar.com/wp-content/uploads/2019/06/Godox_AD200_20171010.pdf#page=11). No SPD is synthesized from this CCT.
