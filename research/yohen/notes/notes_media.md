# 藤田、龍光院及杭州残片影像核查（2026-11-01）

本分工仅用 web 检索并读取来源页。未能下载原文件、解码原图或播放视频，故全部登记 `remote_only`；不得把拟保存文件名理解为已存在。分辨率仅填写 Commons 文件页明确记载的原始像素数，其他一律未核验。图搜自动生成的图片描述未作为角度、照明或器物身份的证据。`sources_media.csv` 保存页面 URL 与直接资源 URL；其中 PDF 图版行只是嵌入图引用，不能当成独立 JPEG 已取得。

## 优先次序与排雷

1. 藤田优先取文化厅两图、日本博官方文化项目图、故宫月刊小林仁亲摄图3，再用 Commons 的 Key-museo 实拍作为不同拍摄条件的补充。Commons《Temmoku tea bowl Fujita Bijutsukan.jpg》虽为 1413×2464，但文件历史明确出现 `color added`、`colorized`、`lightened`，当前版本不能作为真实颜色标定。源图为1954年藤田馆图录；Commons 公有领域标签只是其文件页的许可主张。
2. 龍光院优先用 MIHO 展览页及2018年故宫月刊图4（明确来源至图录），再辅以 Internet Museum 的2019年报道照片与两段展览视频。美术手帖 19335 图片有龙光院图注，值得取原图；图片搜索曾把同站 19202 的藤田图误配进龙光院结果，须按正文图注而非搜索摘要判断身份。
3. 杭州至少须分开登记两件：2009年原东南化工厂附近发现、古越会馆藏；2017年传杭州新发现、述郑斋藏。2018年小林仁原文 p27 明确二者均非正式考古发掘所得，不能将通俗文章所称“出土”当成有正式考古层位记录。2018年文中科学分析仍属未来计划。
4. 暂未取得另一两碗或杭州残片经视觉核验的垂直俯视、完整外壁展开、圈足底视或带标准色卡照片。当前目录不能满足从照片精确数斑点、定光源或反演光谱的要求。

## 照明有来源依据的资料

CCS官方2017-10-17新闻稿：[京都国立博物馆国宝展自然光 LED](https://www.ccs-inc.co.jp/museum/results/others/kyoto.pdf)，2页全文已读取。p1明确2017京博展的龍光院曜变专用照明使用 CCS“自然光 LED”，由キテラス设计；说明该 LED 采用紫色 LED，涵盖可见波段。**这只是特定2017年展场的照明，不能套用到2019年 MIHO 或图录照片**；没有本分工核实到可输入渲染器的 SPD、色温、照度、光源尺寸和位置。

Commons `Yohentenmoku 2.JPG` 的文件页 EXIF：2013-12-13，iPhone 5、1/20s、f/2.4、ISO80、自动白平衡、闪光灯未触发。仅能据此确认未闪光，不足以确定场馆光源光谱或摄影方位。
