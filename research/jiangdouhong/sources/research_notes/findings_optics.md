# 铜红釉光学与定量证据（供 report.md 整合）

本分工只研究光学、实测量与可复用代码。尚未找到**康熙豇豆红印盒本体**的粒径、Cu⁰ 体积分数、釉厚及校准反射谱成套数据；下列古代窑变铜红、祭红与现代复烧样必须区分，不能改写成豇豆红印盒实测。

## 1. 最有用的直接实验 + 光学模型

### A. Cuvelier et al. 2012：现代铜红釉 B23，非清代标本

P.-A. Cuvelier, C. Andraud, D. Chaudanson, J. Lafait, S. Nitsche, **Copper red glazes: a coating with two families of particles**, *Applied Physics A* **106**, 915–929 (2012), [DOI](https://doi.org/10.1007/s00339-011-6707-3), [作者全文 PDF](https://arxiv.org/pdf/1302.2302), [arXiv 记录](https://arxiv.org/abs/1302.2302)。本地 `papers/optics_cuvelier_2012_copper_red_glazes.pdf`，16 页，以下页码是 PDF 页序。

| 数据 | 数值 / 判读 | 证据性质及定位 |
|---|---|---|
| 标本 | 现代试片 B23，1280 °C 还原烧制；配方外加 CuCO₃ 0.6 wt%、SnO 0.6 wt% | 制作记录；p.2 §2.1；不是古代工艺复原结论 |
| 总釉厚 / 发色区 | **0.3 mm / 150 μm**；红区上下都有无色区 | 截面实测 / 图示；p.3 Fig.2 |
| 光学切片 | 35、149、114、72 μm | 制样实测；p.3 §2.1 |
| 小粒子直径 | **10–50 nm**；六张 TEM 图统计的数均约 **25 nm**，由平均体积折算直径约 **30 nm** | TEM 实测；pp.4–5 Fig.4 / 4c |
| 大粒子直径 | **70–150 nm**，数量稀少 | TEM 实测；p.5 Fig.5，p.7 §3.4 |
| Cu 价态 | 所测 5 个小粒子、2 个大粒子 EELS 均为金属铜；截面扫描只有一个粒子边缘检出氧化物 | 局部 EELS 实测；p.7 §3.3。不能解释为全釉所有 Cu 原子均 Cu⁰ |
| Cu 体积分数 | TEM 粗估小粒子约 **12×10⁻⁴**；由投料完全变 Cu 估 **9×10⁻⁴** | 前者显微统计估值，后者投料计算，非同一测量 |
| 最佳光谱模型量 | 总 Cu 体积分数 **8×10⁻⁴ = 0.08 vol%**；大粒子占全部金属铜体积的 **20–30%**，代表大粒子直径 **100 nm**，红层 **150 μm** | 透射 / 漫反射联合拟合，pp.12–13 Fig.17–18；不是直接称量浓度 |
| 反射 / 透射谱 | Fig.3b、3c 实测；Fig.18 实测与模型对照 | 可追踪曲线，未附 CSV 数据 |

**模型机制〔论文 + 本样验证〕**：小粒子主要吸收，大粒子主要散射；Mie 单粒子截面 + four-flux 辐射传输，配合透明基釉与反射瓷胎。pp.10–15 / Fig.12–20 给尺寸、浓度和两族比例的色图。在该模型中，增加小粒子可使颜色更暗、更饱和，增加大粒子可提亮并去饱和，适于解释“粉润”而非直接做金属铜面。[全文](https://arxiv.org/pdf/1302.2302)

**注意原文笔误**：p.13 §5.2 写 small particles “non absorbing”，与摘要、§4.1 和全文机制相矛盾，应按小粒子主要吸收理解，报告不照抄该句。[全文](https://arxiv.org/pdf/1302.2302)

## 2. 开源代码到底有哪些

- **核查结论〔检索范围内未发现〕**：上述两篇全文和公开记录没有给可下载的完整铜红釉模型仓库；按论文标题 + code / github / supplementary / copper-red glaze shader 检索，也未找到经验证的铜红釉完整渲染器材质。因此应写“有现成的物理模型，没有找到现成的、验证过的豇豆红材质资产”。不能写“没有任何代码存在”。[Cuvelier 记录](https://arxiv.org/abs/1302.2302)、[Li / Lei 记录](https://arxiv.org/abs/2208.08043)
- **可复用底层求解器〔官方代码〕**：[miepython](https://github.com/scottprahl/miepython) 为 MIT 开源，可算球形粒子的消光、散射、吸收效率、各向异性 g 和角分布；有原生数值基准。它**没有**透明顶层 / 瓷胎 / 铜离子绿斑 / 粉色云斑 / 粗糙表面 / 参数反演这一完整釉体系，不能直接把它称为“铜红釉 shader”。[官方仓库](https://github.com/scottprahl/miepython)
- Li / Lei p.7 明确使用 MATLAB 进行 Mie 系数计算，参考 Mätzler 2002《MATLAB Functions for Mie Scattering and Absorption》；这是单球光学工具线索，不代表论文端到端脚本已公开。[PDF pp.7,26](https://arxiv.org/pdf/2208.08043)

## 3. 给渲染的有依据外推（都标作工作假设）

**推荐结构〔渲染推测〕**：表面用光滑介电透明釉；其下为有吸收 / 体散射的带色层；底部瓷胎提供漫反射。以 2012、2022 的粒径与体积分数做数量级起点，然后依照片拟合，而不宣称重建了康熙工艺。局部苔点另用 Cu²⁺ 离子相关选择吸收或独立绿区，不能将绿色解释为“金属铜粒子变绿”；绿色确切化学需直接分析证据。[2012 实验模型](https://arxiv.org/pdf/1302.2302)、[2022 模型](https://arxiv.org/pdf/2208.08043)

要做光谱渲染，可把粒径分布和体积分数转成 μa(λ)、μs(λ)、phase(θ,λ)，叠加 Fresnel 表层及瓷胎边界；只实现 RGB 时可先烘焙反射谱 LUT。**这是基于论文机制的实现建议，不是论文提供的完成材质**。[Mie 工具能力](https://github.com/scottprahl/miepython)、[四通量模型实测校验](https://arxiv.org/pdf/1302.2302)

**关键尺度提醒〔几何推论〕**：25–150 nm 铜粒子比特写可见的苔点小很多，纳米粒子是每个像素的有效介质成分；宏观可见斑点应由局部浓度、价态、层厚和微结构分区表达，不能把每个可见绿斑画成一颗纳米铜球。推论所用粒径见上述 TEM 实测。
