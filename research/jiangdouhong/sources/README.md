- `*_api.json` 保存馆藏API响应原文；字段内部冲突也予以保留，报告已注明不用于定尺度。

- `research_notes/` 是分工核查笔记，保留页码、摘要/正文区别及未采用线索；主报告已做整合与范围取舍。
