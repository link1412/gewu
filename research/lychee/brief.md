# 荔枝(Litchi chinensis)的横截面:解剖尺寸、光学参数、参照照片

我们要用物理渲染(路径追踪)做一个切开的荔枝的横截面:红色有龟裂片的果皮、白色半透明多汁的假种皮(果肉)、中间褐色发亮的种子。需要的是能直接填进模型的数,每个数带出处(论文、书、数据库,写清是实测、引用别人的,还是你推的)。

## 要什么

1. **解剖和尺寸**(最好按品种,如妃子笑、桂味、糯米糍、黑叶;有就分):
   - 果实形状、纵径、横径;
   - 果皮厚度;果皮外表的龟裂片(tubercle / protuberance)的大小、间距、高度、形状,片中间的尖刺(若有)的高度;缝合线;
   - 果皮的分层(外果皮、中果皮、内果皮),内表面(白色或带粉、紫的那层膜)是什么、多厚;
   - 假种皮(果肉)的厚度、从哪里长出来、怎么包住种子;细胞的大小和形状(显微照片里量的);里面的维管束、纹理;
   - 种子的大小、形状、种皮的颜色和光泽;种脐;
   - 果肉和果皮之间、果肉和种子之间有没有空隙或膜。
2. **光学**:
   - 果肉(假种皮)的吸收系数 μa(λ)、约化散射系数 μs'(λ)(或 μs 和 g),最好 400–1000 nm 的谱;方法(积分球加逆倍增、空间分辨、时间分辨……)。荔枝没有的话,给最接近的实测(龙眼、葡萄、红毛丹、山竹或别的透明多汁的果肉),标明是替代;
   - 果汁的折射率(或可溶性固形物 Brix,我们自己换算);
   - 果皮外表的反射光谱(新鲜的、放了几天变褐的);花青素的含量;色度 L*a*b* 随采后时间的变化;
   - 种子种皮的反射光谱或颜色,光泽;
   - 果肉切面、果皮的表面粗糙度或光泽,若有。
3. **参照照片**(真照片):
   - 荔枝的横切面、纵切面,最好带尺子或已知尺寸;
   - 果皮表面的微距;
   - 背光下的荔枝果肉。
   - 图下载到本目录的 `photos/`,每张记下来源网址、作者、授权、拍摄条件(光、能不能推出比例尺)。只作参照,不限授权。
4. **采后的变化**:采后几小时到几天,果皮变褐、果肉失水,有实测的时间曲线就给。

## 交什么

- 报告写进本目录的 `report.md`。中文,每个数带出处和标记:[M] 来源自己量的、[I] 来源引用的、[D] 你推的。
- 数据(光谱、表)存成 CSV 放 `data/`,在报告里说明列的含义和单位。
- 找不到的写「没找到」,不要编。
