How it was made

Picture
Every frame is generated by code. Geometry, materials, lights and motion are written in Python, path traced in Blender Cycles, and developed from linear floating-point frames in a hand-written darkroom.
Sound
The notes and structure are written in code. The instruments are sampled, not synthesized by the program: the choir and strings from MuseScore General (MIT), the low drones and reeds from Keyscape.
People and machines
link1412 set the direction and made the calls. Claude Opus 5.5 wrote the code and ran the renders.
